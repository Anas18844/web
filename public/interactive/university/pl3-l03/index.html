الـ Functional Programming و F#

في الـ Functional programming البرنامج عبارة عن دوال و قيم مش بتتغير و تحويلات.

F#: لغة statically typed، و expression-oriented، من عيلة ML.

let square x = x * x
let message = sprintf "Square is %d" (square 5)
printfn "%s" message // Square is 25
  1. let بتعرّف قيمة أو دالة.
  2. بنادي الدالة من غير أقواس: square 5.
  3. sprintf بترجع نص، و printfn بتطبع.
  4. %d للرقم، و %s للنص.
فخ: sprintf بترجع نص ومش بتطبع. و printfn هي اللي بتطبع.

Immutability و Mutation و Shadowing

1. Immutable by default

let x = 10
let y = x + 5  // y = 15

القيم بعد let مش بتتغير.

2. Mutation: لازم تطلبها صراحة

let mutable counter = 0
counter <- counter + 1  // counter = 1

mutable بتسمح بالتعديل، والتعديل بـ <-.

3. Shadowing: اسم قديم لقيمة جديدة

let x = 10
let x = x + 5  // shadowing; valid -> x = 15

Pure Functions

Pure function: شرطين:

  1. نفس الدخل يدي نفس الخرج دايمًا.
  2. مفيش side effects (مش بتغير حاجة بره).
let add a b = a + b // pure

let mutable total = 0
let addToTotal x =
    total <- total + x
    total // impure

ليه addToTotal impure؟ لأنها بتغير total بره، ونفس الدخل بيدي نتايج مختلفة: addToTotal 5 أول مرة 5، وتاني مرة 10.

الـ pure expressions بتدعم referential transparency: تقدر تبدّل الاستدعاء بقيمته من غير ما البرنامج يتغير.
تعرفها إزاي؟ بص على <- لمتغير بره، أو printfn، أو قراءة ملف. أي واحدة منهم تخليها impure.

Pattern Matching و Discriminated Unions

match ... with بتقارن قيمة بأشكال، وأول شكل يطابق بيتنفذ من فوق لتحت.

let describeValue input =
    match input with
    | 0 -> "Zero"
    | n when n < 0 -> "Negative"
    | _ -> "Positive"
  • when: شرط إضافي (guard).
  • _: wildcard، أي حاجة.
  • بتشتغل على tuples، و lists، و discriminated unions.
  • الـ compiler بيطلع warning لو الحالات ناقصة.

Discriminated Unions

نوع له أشكال محددة، وكل شكل ممكن يشيل بيانات.

type Shape =
    | Circle of float
    | Rectangle of float * float

let area = function
    | Circle r -> System.Math.PI * r * r
    | Rectangle (w,h) -> w * h

function اختصار لـ fun x -> match x with.

نتتبع

area (Rectangle (3.0, 4.0)): الشكل Rectangle، و w = 3.0 و h = 4.0، والنتيجة 12.0.

فخ: الترتيب مهم. لو _ الأول، كل الحالات اللي بعدها مش هتتنفذ.

Recursion و Tail Recursion

دالة بتنادي نفسها. وفي F# لازم rec، ولازم base case.

let rec factorial n =
    if n = 0 then 1
    else n * factorial (n - 1)

نتتبع factorial 3

  1. 3 * factorial 2
  2. 3 * (2 * factorial 1)
  3. 3 * (2 * (1 * factorial 0))
  4. 3 * 2 * 1 * 1 = 6

الضرب مستني بعد الاستدعاء، فده مش tail recursion.

Tail Recursion

الاستدعاء هو آخر حاجة في الدالة (final position)، ودي بتسمح بـ optimizations.

let factorialTR n =
    let rec loop acc n =
        if n <= 1 then acc
        else loop (acc * n) (n - 1)
    loop 1 n
callaccn
loop 1 414
loop 4 343
loop 12 2122
loop 24 1241 → returns 24
فخ: n * factorial (n-1) الاستدعاء مش آخر حاجة، لأن بعده ضرب. و loop (acc*n) (n-1) هو آخر حاجة.

Composition و Pipelines

|>: ابعت القيمة للدالة

5 |> square        // same as: square 5
[1;2] |> List.sum  // 3

>> و <<: نركّب دالتين

let double x = x * 2
let increment x = x + 1
let f = double >> increment
f 3 // 7
  • >> من الشمال لليمين: double الأول، فـ 3 → 6 → 7.
  • << من اليمين للشمال: double << increment بتعمل increment الأول، فـ 3 → 4 → 8.

الـ Pipeline الكامل

[1..10]
|> List.filter (fun x -> x % 2 = 0)  // [2;4;6;8;10]
|> List.map (fun x -> x*x)           // [4;16;36;64;100]
|> List.sum                          // 220
معمل: >> و << بأرقامك
فخ: لو الترتيب في الـ pipeline اتغير، النتيجة ممكن تتغير: filter قبل map غير map قبل filter.

Lazy Evaluation و Sequences (آخر الداخل في الميد)

F# عادةً strict: بتحسب القيمة فورًا. بس بتدعم lazy: ما تحسبش غير لما تحتاج.

let lazyValue = lazy (printfn "Computed"; 2 + 2)
let result = lazyValue.Force()
  1. أول سطر: مفيش حساب، ومفيش طباعة.
  2. Force(): بيحسب، ويطبع Computed، ويرجع 4.
  3. لو ناديت Force() تاني: بيرجع 4 من غير طباعة، لأن القيمة اتحفظت.
معمل: دوس Force أكتر من مرة

Sequences: عناصر عند الطلب

let naturals = Seq.initInfinite id
naturals |> Seq.take 5 |> Seq.toList
// [0;1;2;3;4]
  • Seq.initInfinite id: سلسلة لا نهائية: 0، 1، 2...
  • id: دالة بترجع اللي دخلها.
  • Seq.take 5: خد أول 5.
  • Seq.toList: حوّل لقايمة.
السلسلة لا نهائية ومع كده البرنامج بيخلص، لأن العناصر بتتولد on demand.
فخ: البداية 0 مش 1. يعني Seq.take 5 بيدي [0;1;2;3;4].

الخلاصة

السطور اللي تراجعها الصبح

  1. F#: statically typed، و expression-oriented، من عيلة ML.
  2. Immutable by default. و mutable مع <-. و let التانية shadowing.
  3. Pure: نفس الدخل نفس الخرج ومفيش side effects. و addToTotal impure.
  4. match: when guard، و _ wildcard، وأول تطابق من فوق. والناقص warning.
  5. let rec و base case. و Tail: الاستدعاء final position.
  6. map و filter و fold و map2. و [1..10] even squares sum = 220.
  7. >> شمال ليمين: f 3 = 7. و << يمين لشمال.
  8. lazy بتتحسب عند Force() مرة واحدة. و Seq.take 5 = [0;1;2;3;4].
