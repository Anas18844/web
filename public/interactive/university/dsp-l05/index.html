تحليل Fourier: الـ Magnitude والـ Phase

بدل ما نشوف الإشارة عينة بعينة، نشوف فيها إيه من ترددات. ومعاها الـ convolution الصعبة بتبقى ضرب عادي.

الجزء 1

ليه Fourier؟

الإشارة ليها وشين: time domain (بتتغير إزاي)، وfrequency domain (فيها أنهي ترددات).

y[n] = x[n] * h[n]  ⇔  Y(ejω) = X(ejω) H(ejω)
الـ convolution في الوقت = ضرب في التردد. وده سبب وجود الدرس كله.

إثبات: ejωn بتطلع زي ما هي

  1. الدخل x[n] = ejωn.
  2. y[n] = Σₖ h[k] x[n−k] = Σₖ h[k] ejω(n−k).
  3. طلّع ejωn بره: y[n] = ejωn Σₖ h[k] e−jωk.
  4. الباقي هو H(ejω)، يبقى y[n] = H(ejω) ejωn.
المعنى: الـ system بيحتفظ بنفس التردد، وبيغير الـ amplitude والـ phase بس.
الجزء 2

الـ Magnitude والـ Phase

H(ejω) = Σₖ h[k] e−jωk
H = Hr + jHi = |H| ejφ
|H| = √(Hr² + Hi²)     φ = tan⁻¹(Hi / Hr)

|H|: الـ system بيكبر أو يصغر التردد ده قد إيه. φ: بيزيحه قد إيه.

غلطات في السلايدز: سلايد 5 كاتب مقام الـ phase Hj والصح Hr. وسلايد 6 كاتب ejω(n−k) والصح e−jωk.

الخطوات التلاتة في مثال المحاضرة

h[0] = ½, h[1] = ½

1. H: H = ½ + ½e−jω = 0.5(1 + e−jω)

Euler: 1 + e−jω = 2cos(ω/2)e−jω/2، يبقى H = cos(ω/2)e−jω/2

2. Magnitude: |ejθ| = 1، يبقى |H| = |cos(ω/2)|

3. Phase: ∠H = −ω/2 لما cos(ω/2) > 0

تريك الاستخراج: طلّع نص الأس المشترك بره:
1 + e−jθ = 2cos(θ/2) e−jθ/2
1 − e−jθ = 2j sin(θ/2) e−jθ/2

ومع θ = 2ω نفس القانون: 1 + e−j2ω = 2cos(ω) e−jω.

تريك عند ω محددة: عوّض بـ Euler: e−jθ = cosθ − j sinθ. وخد بالك: e−jπ/2 = −j، وe−jπ = −1.
فخاخ الـ phase:
• لو الجزء الحقيقي سالب، ربع الدايرة يتغير: H = −1 الـ phase بتاعها π مش 0. استخدم atan2(Hi, Hr).
• لما الـ cos أو sin سالب، ضيف π.
• لما H = 0، الـ phase undefined.
• j = ejπ/2، فـ j بتضيف π/2 للـ phase.

5 أسئلة سريعة

مسائل بأرقام جديدة

حل بالورقة الأول

1. h[0] = 1, h[1] = 1. أوجد H و|H| والـ phase.
H = 1 + e−jω = 2cos(ω/2)e−jω/2
|H| = 2|cos(ω/2)|
∠H = −ω/2 لما cos(ω/2) > 0، ونضيف π لما يكون سالب، وundefined عند ω = π.
2. h[0] = 1, h[2] = 1. أوجد H و|H| والـ phase.
H = 1 + e−j2ω = e−jω(ejω + e−jω) = 2cos(ω)e−jω
|H| = 2|cos ω|، و∠H = −ω لما cos ω > 0، ونضيف π لما يكون سالب، وundefined عند cos ω = 0.
3. h[0] = 1, h[1] = −1: احسب H و|H| والـ phase عند ω = π/2.
e−jπ/2 = −j، يبقى H = 1 + j، و|H| = √2، و∠H = π/4.
4. H = 1 − j، وبعدها H = −1: أوجد المقدار والـ phase.
الأولى: √2 و−π/4. التانية: 1 وπ، وده مثال على الفخ.

5 سطور تراجعهم قبل الامتحان

  1. Convolution في الوقت = ضرب في التردد: Y = XH.
  2. H(ejω) = Σ h[k]e−jωk.
  3. |H| = √(Hr²+Hi²) وφ = tan⁻¹(Hi/Hr).
  4. طلّع نص الأس: 1 ± e−jθ تبقى cos أو 2j sin.
  5. الـ cos السالب بيضيف π، وH = 0 معناها phase undefined.
