شيت الـ Magnitude & Phase

Problem 1 · Basic

Given h[0] = 1 and h[1] = 1/2, find H(ejω), |H(ejω)|, and ∠H(ejω).
1. الوصفة اللي هنمشي بيها في الشيت كله• H: كل عينة h[k] تتضرب في e−jωk وتتجمع: H(ejω) = Σₖ h[k]e−jωk
• Magnitude: طول الرقم المركب |H| = √(Hᵣ² + Hᵢ²)
• Phase: زاويته ∠H = atan2(Hᵢ, Hᵣ)
والأداة الأساسية: e−jω = cos ω − j sin ω
2. اكتب Hk = 0 بتدي e0 = 1، و k = 1 بتدي e−jω:
H(ejω) = 1 + ½e−jω
3. افصل الحقيقي عن التخيليعوّض e−jω = cos ω − j sin ω:
H = 1 + ½cos ω − j ½sin ω
Hᵣ = 1 + ½cos ω , Hᵢ = −½sin ω
4. الـ Magnitude
|H|² = (1 + ½cos ω)² + (½sin ω)² = 1 + cos ω + ¼cos²ω + ¼sin²ω
وبما إن cos² + sin² = 1:
|H|² = 5/4 + cos ω → |H| = √(5/4 + cos ω) = ½√(5 + 4cos ω)
5. الـ Phase
∠H = atan2(−½sin ω, 1 + ½cos ω) = −tan⁻¹( sin ω / (2 + cos ω) )
ينفع نستخدم tan⁻¹ العادية لأن Hᵣ = 1 + ½cos ω ≥ ½ دايمًا موجبة.
6. راجع بنقطتين سهلين• عند ω = 0: H = Σh = 1 + ½ = 1.5، والقانون: √(5/4 + 1) = 1.5 ✓
• عند ω = π: H = 1 − ½ = 0.5، والقانون: √(5/4 − 1) = 0.5 ✓

Problem 2 · Lecture example

Given h[0] = 1/2 and h[1] = 1/2, find H(ejω), magnitude, and phase.
1. اكتب H
H = ½ + ½e−jω = ½(1 + e−jω)
2. الحيلة: اطلع نص الـ delay برااطلع e−jω/2 عامل مشترك، عشان اللي جوه يبقى متماثل:
H = ½ e−jω/2 (ejω/2 + e−jω/2)
جرّب تضربها تاني: e−jω/2·ejω/2 = 1 و e−jω/2·e−jω/2 = e−jω ✓
3. Euler: الأقواس تبقى cosejθ + e−jθ = 2cos θ و ejθ − e−jθ = 2j sin θ، يعني القوس = 2cos(ω/2):
H = cos(ω/2) e−jω/2
دلوقتي H = (رقم حقيقي) × (حاجة طولها 1).
4. الـ Magnitude|e−jω/2| = 1، فالطول كله من الجزء الحقيقي:
|H| = |cos(ω/2)|
5. الـ Phaseزاوية e−jω/2 هي −ω/2.
• لما cos(ω/2) > 0 (يعني |ω| < π): ∠H = −ω/2
• لو بقى سالب: زوّد π (السالب = زاوية π)
• عند ω = ±π: cos(π/2) = 0، فـ H = 0 والـ phase undefined
6. اكتب الإجابة
H = cos(ω/2)e−jω/2 , |H| = |cos(ω/2)| , ∠H = −ω/2 (|ω| < π)
ده lowpass: عند ω = 0 الطول 1، وعند ω = π صفر.

Problem 3 · Three samples

Given h[0] = h[1] = h[2] = 1/3, find H(ejω), magnitude, and phase. Simplify where possible.
1. اكتب H
H = ⅓(1 + e−jω + e−j2ω)
2. اطلع الحد اللي في النص برا3 عينات، فالنص عند k = 1. اطلع e−jω:
H = ⅓ e−jω(ejω + 1 + e−jω)
3. Eulerejω + e−jω = 2cos ω:
H = ⅓ e−jω(1 + 2cos ω)
4. الـ Magnitude
|H| = |1 + 2cos ω| / 3
5. الـ Phase: امتى الجزء الحقيقي بيغير إشارته؟1 + 2cos ω = 0 لما cos ω = −½، يعني ω = ±2π/3.
• |ω| < 2π/3: موجب → ∠H = −ω
• 2π/3 < |ω| ≤ π: سالب → ∠H = −ω ± π
• عند ω = ±2π/3: H = 0 والـ phase undefined
6. راجع• ω = 0: Σh = 1، والقانون (1 + 2)/3 = 1 ✓
• ω = π: ⅓ − ⅓ + ⅓ = ⅓، والقانون |1 − 2|/3 = ⅓ ✓

Problem 4 · Difference system

Given h[0] = 1 and h[1] = −1, find H(ejω), magnitude, and phase.
1. اكتب H واطلع نص الـ delay
H = 1 − e−jω = e−jω/2(ejω/2 − e−jω/2)
2. Euler بالسالب: بتطلع j sinejθ + e−jθ = 2cos θ و ejθ − e−jθ = 2j sin θ، يعني:
H = 2j sin(ω/2) e−jω/2
3. الـ Magnitude|j| = 1 و |e−jω/2| = 1:
|H| = 2|sin(ω/2)|
4. الـ Phase: الـ j بتزود π/2j = ejπ/2، يعني زاويتها π/2. الزوايا بتتجمع:
• 0 < ω ≤ π (sin > 0): ∠H = π/2 − ω/2
• −π ≤ ω < 0 (sin < 0، يعني زاوية π زيادة): ∠H = −π/2 − ω/2
• عند ω = 0: H = 0، فالـ phase undefined
5. راجععند ω = π: H = 1 − (−1) = 2. والقانون: |H| = 2sin(π/2) = 2 و ∠H = π/2 − π/2 = 0 ✓
ده highpass: صفر عند ω = 0، وأكبر حاجة عند π.

Problem 5 · Weighted samples

Given h[0] = 1/2 and h[1] = −1/2, find H(ejω), magnitude, and phase.
1. لاحظ إنها نص Problem 4
H = ½(1 − e−jω)
وإحنا عارفين من Problem 4 إن 1 − e−jω = 2j sin(ω/2)e−jω/2.
2. H
H = j sin(ω/2) e−jω/2
3. الـ Magnitude والـ Phase
|H| = |sin(ω/2)|
الضرب في ½ (رقم موجب) بيغير الطول بس، ما بيغيرش الزاوية. يعني الـ phase زي Problem 4 بالظبط: π/2 − ω/2 لما sin موجب، و −π/2 − ω/2 لما سالب، و undefined عند ω = 0.

Problem 6 · Delayed impulse

Given h[2] = 1 and all other samples are zero, find H(ejω), magnitude, and phase.
1. اكتب Hفيه عينة واحدة بس عند k = 2:
H = 1 · e−j2ω = e−j2ω
2. الـ Magnitude والـ Phaseدي على الصورة ejθ مباشرة، و |ejθ| = 1:
|H| = 1 , ∠H = −2ω
3. الفهمالـ delay بخطوتين ما بيغيرش طول أي تردد (|H| = 1)، بيزود بس phase خطية ميلها −2. القاعدة: delay بـ d = phase قيمتها −dω.

Problem 7 · Complex response

A system has H(ejω) = 1 + j. Find its magnitude and phase.
1. الجزء الحقيقي والتخيليHᵣ = 1 و Hᵢ = 1
2. الـ Magnitude
|H| = √(1² + 1²) = √2
3. الـ Phase
∠H = atan2(1, 1) = π/4 = 45°
النقطة (1, 1) في الربع الأول، فمفيش تصحيح.

Problem 8 · Frequency-dependent response

Given H(ejω) = 1 − e−jω, rewrite it in a form that makes the magnitude and phase easier to identify. Then find both.
1. دي Problem 4 بالظبط1 − e−jω هي H بتاعة h = {1, −1}. الفرق إن السؤال هنا طالب الـ rewrite صريح.
2. الشكل المطلوباطلع e−jω/2 وطبّق Euler:
H = e−jω/2(ejω/2 − e−jω/2) = 2j sin(ω/2) e−jω/2
3. الإجابة
|H| = 2|sin(ω/2)|
∠H = π/2 − ω/2 (sin(ω/2) > 0)
وتتعدل بـ π لما sin سالب، و undefined عند ω = 2πm.

Problem 9 · Evaluate at a frequency

For h[0] = 1/2 and h[1] = 1/2, evaluate H, magnitude, and phase at ω = π/2.
1. احسب e−jπ/2
e−jπ/2 = cos(π/2) − j sin(π/2) = 0 − j = −j
2. عوّض في H
H = ½ + ½(−j) = ½ − ½j
3. الـ Magnitude
|H| = √(¼ + ¼) = √(½) = √2/2 ≈ 0.707
4. الـ Phase
∠H = atan2(−½, ½) = −π/4 = −45°
النقطة في الربع الرابع (حقيقي موجب، تخيلي سالب).
5. راجع بقانون Problem 2|cos(π/4)| = 0.707 ✓ و −ω/2 = −π/4 ✓

Problem 10 · Challenge

Given h[0] = 1/4, h[1] = 1/2, and h[2] = 1/4, find H(ejω), magnitude, and phase. Identify frequencies where the magnitude is zero and phase is undefined.
1. اكتب H واطلع الحد اللي في النص
H = ¼ + ½e−jω + ¼e−j2ω = e−jω(¼ejω + ½ + ¼e−jω)
2. Euler¼(ejω + e−jω) = ½cos ω:
H = e−jω(½ + ½cos ω)
3. بسّطها بقانون نص الزاوية½(1 + cos ω) = cos²(ω/2):
H = cos²(ω/2) e−jω
(وفيه طريقة تانية: H = ¼(1 + e−jω)² = (cos(ω/2)e−jω/2)²، نفس النتيجة.)
4. الـ Magnitude والـ Phasecos² عمرها ما بتبقى سالبة، فمش محتاجين absolute ولا تصحيح بـ π:
|H| = cos²(ω/2) , ∠H = −ω
5. فين H = 0؟cos(ω/2) = 0 لما ω/2 = π/2 + mπ، يعني ω = (2m + 1)π (يعني ±π).
هناك الـ magnitude = 0 والـ phase undefined.
6. راجع• ω = 0: Σh = 1 ✓
• ω = π: ¼ − ½ + ¼ = 0 ✓
