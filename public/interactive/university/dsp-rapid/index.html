القوانين في صورة أسئلة

قول الإجابة بصوتك، وبعدين دوس.

1. أوجد N لـ cos(ω₀n)؟
N = 2πk/ω₀، وأصغر k تدي N صحيح. ولو π مش بتروح: aperiodic.
2. N لمجموع إشارتين؟
N = lcm(N₁, N₂)
3. xₑ[n] ؟
½(x[n] + x[−n])
4. xₒ[n] ؟
½(x[n] − x[−n])
5. Conjugate symmetric part؟
½(x[n] + x*[−n])
6. δ[n] بدلالة u؟
u[n] − u[n−1]
7. Linear معناها؟
T{ax₁ + bx₂} = aT{x₁} + bT{x₂} (additive + homogeneous)
8. Shift-invariant معناها؟
T{x[n−n₀]} = y[n−n₀]
9. Causal معناها؟
الخرج مش معتمد على مستقبل. و LSI: h[n] = 0 لـ n < 0
10. BIBO stable معناها؟
دخل محدود يدي خرج محدود. و LSI: Σ|h[n]| < ∞
11. Invertible معناها؟
كل دخل ليه خرج مختلف، فنقدر نرجّع x.
12. الـ Convolution؟
y[n] = Σₖ x[k]h[n−k]
13. طول y وبدايتها؟
L_y = L_x + L_h − 1، والبداية مجموع البدايات.
14. مراجعة الـ Convolution؟
Σy = Σx · Σh
15. x * δ[n−k] ؟
x[n−k]
16. aⁿu[n] * u[n] ؟
((1 − an+1)/(1 − a)) u[n]، ولو a = 1: (n+1)u[n]
17. الـ Frequency response؟
H(ejω) = Σₖ h[k]e−jωk
18. الـ Magnitude والـ Phase؟
|H| = √(Hᵣ² + Hᵢ²) و ∠H = atan2(Hᵢ, Hᵣ)
19. 1 + e−jω ؟
2cos(ω/2)e−jω/2
20. 1 − e−jω ؟
2j sin(ω/2)e−jω/2
21. ejθ + e−jθ و ejθ − e−jθ ؟
2cos θ و 2j sin θ
22. Convolution في الزمن = ؟
ضرب في التردد: Y = XH
23. H عند ω = 0 و ω = π ؟
Σh[k] و Σ(−1)k h[k]
24. الـ Phase لما |H| = 0 ؟
undefined
