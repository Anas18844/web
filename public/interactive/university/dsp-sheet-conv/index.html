Problem 1 · Finite-sequence convolution

Given x[n] = {1, 2} and h[n] = {3, 4}. Both sequences start at n = 0. Calculate y[n] = x[n] * h[n].
1. اكتب القيم وجنب كل قيمة الـ index بتاعهاأول حاجة في أي convolution: ما تبصش على الأرقام لوحدها، بص على كل رقم واقف فين.
x[0] = 1 , x[1] = 2
h[0] = 3 , h[1] = 4
2. حدد الخرج هيبدأ فين وطوله قد إيهقاعدتين بيوفروا عليك نص الشغل:
• البداية = بداية x + بداية h = 0 + 0 = 0
• الطول = Lₓ + Lₕ − 1 = 2 + 2 − 1 = 3
يبقى الخرج عند n = 0, 1, 2 بس، وغير كده صفر.
3. الفكرة: y[n] بتجمع كل الأزواج اللي مجموع الـ index بتاعهم = nالقانون y[n] = Σₖ x[k] h[n−k]. لاحظ إن index الـ x (اللي هو k) + index الـ h (اللي هو n−k) = n.
يعني y[n] = مجموع كل x[i]·h[j] اللي فيها i + j = n. اعمل جدول ضرب، والخانات اللي ليها نفس اللون بتتجمع مع بعض:
h[0] = 3h[1] = 4
x[0] = 13y[0]4y[1]
x[1] = 26y[1]8y[2]
4. احسب y[0]الأزواج اللي مجموعها 0: (0, 0) بس.
y[0] = x[0]h[0] = 1 × 3 = 3
5. احسب y[1]الأزواج اللي مجموعها 1: (0, 1) و (1, 0).
y[1] = x[0]h[1] + x[1]h[0] = 1×4 + 2×3 = 4 + 6 = 10

ونفس النتيجة بطريقة الـ flip and shift اللي في السلايد: اقلب h فتبقى {4, 3}، وزقها خطوة لحد ما الـ 4 تقف تحت x[0]: 1×4 + 2×3 = 10.
6. احسب y[2]الأزواج اللي مجموعها 2: (1, 1) بس.
y[2] = x[1]h[1] = 2 × 4 = 8
7. راجع واكتب الإجابةمراجعة سريعة: مجموع y = مجموع x × مجموع h.
3 + 10 + 8 = 21 و (1+2)(3+4) = 3 × 7 = 21 ✓
y[n] = {3, 10, 8} , n = 0, 1, 2

Problem 2 · Convolution with a negative starting index

Let x[−1] = 2, x[0] = 1, x[1] = 3 and h[0] = 1, h[1] = −1, h[2] = 2. Calculate y[n] = x[n] * h[n].
1. اكتب القيم بالـ indexخد بالك: x بتبدأ من −1 مش من 0. ده الفخ بتاع المسألة.
x[−1] = 2 , x[0] = 1 , x[1] = 3
h[0] = 1 , h[1] = −1 , h[2] = 2
2. البداية والطول• البداية = −1 + 0 = −1
• الطول = 3 + 3 − 1 = 5
يبقى n من −1 لحد 3.
3. جدول الضربكل خانة مكتوب تحتها هي بتروح لأنهي y. الخانات اللي بنفس اللون بتتجمع:
h[0] = 1h[1] = -1h[2] = 2
x[-1] = 22y[-1]-2y[0]4y[1]
x[0] = 11y[0]-1y[1]2y[2]
x[1] = 33y[1]-3y[2]6y[3]
4. y[−1] و y[0]
y[−1] = x[−1]h[0] = 2×1 = 2
y[0] = x[−1]h[1] + x[0]h[0] = 2×(−1) + 1×1 = −2 + 1 = −1
5. y[1]: الخانة اللي فيها 3 حدودالأزواج: (−1, 2) و (0, 1) و (1, 0).
y[1] = x[−1]h[2] + x[0]h[1] + x[1]h[0] = 2×2 + 1×(−1) + 3×1 = 4 − 1 + 3 = 6
6. y[2] و y[3]
y[2] = x[0]h[2] + x[1]h[1] = 1×2 + 3×(−1) = 2 − 3 = −1
y[3] = x[1]h[2] = 3×2 = 6
7. راجع واكتب الإجابةΣy = 2 − 1 + 6 − 1 + 6 = 12 و Σx · Σh = 6 × 2 = 12 ✓
y[n] = {2, −1, 6, −1, 6} , n = −1, …, 3

Problem 3 · Convolution with a delayed sequence

Let x[0] = 1, x[1] = −2, x[2] = 2 and h[2] = 2, h[3] = 1. Find y[n] = x[n] * h[n].
1. اكتب القيم بالـ indexهنا h هي اللي متأخرة: بتبدأ من 2. يعني h[0] و h[1] أصفار.
x[0] = 1 , x[1] = −2 , x[2] = 2
h[2] = 2 , h[3] = 1
2. البداية والطول• البداية = 0 + 2 = 2
• الطول = 3 + 2 − 1 = 4
يبقى n من 2 لحد 5. الـ delay بتاع h بيزق الخرج كله خطوتين يمين.
3. جدول الضرب
h[2] = 2h[3] = 1
x[0] = 12y[2]1y[3]
x[1] = -2-4y[3]-2y[4]
x[2] = 24y[4]2y[5]
4. احسب القيم
y[2] = x[0]h[2] = 1×2 = 2
y[3] = x[0]h[3] + x[1]h[2] = 1×1 + (−2)×2 = 1 − 4 = −3
y[4] = x[1]h[3] + x[2]h[2] = (−2)×1 + 2×2 = −2 + 4 = 2
y[5] = x[2]h[3] = 2×1 = 2
5. راجع واكتب الإجابةΣy = 2 − 3 + 2 + 2 = 3 و Σx · Σh = 1 × 3 = 3 ✓
y[n] = {2, −3, 2, 2} , n = 2, …, 5

Problem 4 · Convolution using unit-step sequences

Given x[n] = u[n] − u[n−4] and h[n] = u[n] − u[n−3], find y[n] = x[n] * h[n]. Find the nonzero values and a piecewise expression.
1. حوّل الـ unit steps لأرقامu[n] − u[n−N] معناها: 1 من n = 0 لحد n = N−1، وصفر غير كده (pulse طولها N).
• x[n] = u[n] − u[n−4] = 1 عند n = 0, 1, 2, 3 → x = {1, 1, 1, 1}
• h[n] = u[n] − u[n−3] = 1 عند n = 0, 1, 2 → h = {1, 1, 1}
2. البداية والطول• البداية = 0 + 0 = 0
• الطول = 4 + 3 − 1 = 6 → n من 0 لحد 5
3. الفكرة: كله واحدات، فالـ convolution بتعد التداخللما الاتنين كلهم 1، كل حاصل ضرب = 1. يبقى y[n] = عدد الأزواج اللي مجموع الـ index بتاعهم n، يعني عدد الخانات المتداخلة وانت بتزق h على x.
h[0] = 1h[1] = 1h[2] = 1
x[0] = 11y[0]1y[1]1y[2]
x[1] = 11y[1]1y[2]1y[3]
x[2] = 11y[2]1y[3]1y[4]
x[3] = 11y[3]1y[4]1y[5]
4. عد الخانات لكل n
y[0] = 1 , y[1] = 2 , y[2] = 3 , y[3] = 3 , y[4] = 2 , y[5] = 1
الشكل: بيطلع (التداخل بيزيد)، وبعدين ثابت (h داخلة كلها جوه x)، وبعدين بينزل. شكل شبه منحرف (trapezoid).
5. اكتبها piecewise• الجزء الطالع (n = 0, 1, 2): القيم 1, 2, 3 → y = n + 1
• الجزء النازل (n = 3, 4, 5): القيم 3, 2, 1 → y = 6 − n (جرّب: 6−3 = 3 ✓ و 6−5 = 1 ✓)
• برا ده كله صفر.
6. راجع واكتب الإجابةΣy = 12 و 4 × 3 = 12 ✓
y[n] = {1, 2, 3, 3, 2, 1} , n = 0, …, 5
y[n] = 0 (n < 0) ; n + 1 (0 ≤ n ≤ 2) ; 6 − n (3 ≤ n ≤ 5) ; 0 (n > 5)

Problem 5 · Convolution with shifted impulses

Given x[−1] = 1, x[0] = 3, x[1] = −1, x[2] = 2 and h[n] = 2δ[n] − δ[n−1], use the impulse-shifting property to find y[n].
1. الخاصية اللي المسألة طالباهاconvolution مع impulse = نفس الإشارة متزقوقة:
x[n] * δ[n] = x[n] , x[n] * δ[n−k] = x[n−k]
والـ convolution linear، فبنوزعها على كل impulse في h.
2. طلّع معادلة y
y = x * (2δ[n] − δ[n−1]) = 2(x * δ[n]) − (x * δ[n−1])
y[n] = 2x[n] − x[n−1]
يعني: ضعف x، ناقص x متأخرة خطوة.
3. حدد الـ rangex من −1 لـ 2، و h = {2, −1} من 0 لـ 1.
• البداية = −1 + 0 = −1
• الطول = 4 + 2 − 1 = 5 → n من −1 لحد 3
4. اعمل جدول: 2x[n] و x[n−1] تحت بعضx[n−1] هي x متزقوقة خطوة يمين: القيمة اللي كانت عند −1 بقت عند 0 وهكذا.
n−10123
x[n]13−120
2x[n]26−240
x[n−1]013−12
y = 2x[n] − x[n−1]25−55−2
5. القيم واحدة واحدة
y[−1] = 2(1) − 0 = 2
y[0] = 2(3) − 1 = 5
y[1] = 2(−1) − 3 = −5
y[2] = 2(2) − (−1) = 5
y[3] = 2(0) − 2 = −2
6. راجع واكتب الإجابةΣy = 2 + 5 − 5 + 5 − 2 = 5 و Σx · Σh = 5 × (2 − 1) = 5 ✓
y[n] = {2, 5, −5, 5, −2} , n = −1, …, 3

Problem 6 · Convolution of two short signals

Let x[0] = 1, x[1] = 2, x[2] = 1 and h[0] = 1, h[1] = 0, h[2] = −1. Compute the full linear convolution y[n] from n = 0 to n = 4.
1. القيم والـ rangex = {1, 2, 1} و h = {1, 0, −1}، الاتنين من 0.
البداية 0، والطول 3 + 3 − 1 = 5 → n من 0 لحد 4 (زي ما السؤال قايل).
2. جدول الضربخد بالك من الـ 0 في h: الخانات بتاعته صفر، بس لازم تفضل في مكانها.
h[0] = 1h[1] = 0h[2] = -1
x[0] = 11y[0]0y[1]-1y[2]
x[1] = 22y[1]0y[2]-2y[3]
x[2] = 11y[2]0y[3]-1y[4]
3. احسب القيم
y[0] = 1×1 = 1
y[1] = 1×0 + 2×1 = 2
y[2] = 1×(−1) + 2×0 + 1×1 = 0
y[3] = 2×(−1) + 1×0 = −2
y[4] = 1×(−1) = −1
4. راجع واكتب الإجابةΣh = 1 + 0 − 1 = 0، يبقى لازم Σy = 0: 1 + 2 + 0 − 2 − 1 = 0 ✓
y[n] = {1, 2, 0, −2, −1} , n = 0, …, 4

Problem 7 · Convolution of infinite-duration sequences

Let x[n] = aⁿu[n] and h[n] = u[n], where a is a real constant. Find y[n] = x[n] * h[n] for a ≠ 1, then state the result when a = 1. Include the case n < 0.
1. الإشارات لا نهائية، فمفيش جدول. نكتب القانون
y[n] = Σₖ x[k] h[n−k] = Σₖ aᵏu[k] · u[n−k]
الشغل كله إننا نعرف حدود الـ Σ من الـ unit steps.
2. الشرط الأول من xu[k] = 1 بس لما k ≥ 0. يعني الجمع بيبدأ من k = 0.
3. الشرط التاني من hu[n−k] = 1 بس لما n − k ≥ 0، يعني k ≤ n. يعني الجمع بيقف عند k = n.
4. حط الشرطين مع بعض
0 ≤ k ≤ n
• لو n < 0: مفيش k تحقق الشرطين (مفيش overlap) → y[n] = 0
• لو n ≥ 0:
y[n] = Σₖ₌₀ⁿ aᵏ = 1 + a + a² + … + aⁿ
5. قانون الـ geometric series (لما a ≠ 1)متسلسلة هندسية: أول حد 1، والأساس a، وعدد الحدود n + 1.
Σₖ₌₀ⁿ aᵏ = (1 − an+1) / (1 − a)
جرّب n = 1: (1 − a²)/(1 − a) = 1 + a ✓
6. الحالة a = 1القانون فيه 1 − a في المقام، فلو a = 1 بيبقى قسمة على صفر. بنرجع للجمع نفسه: 1 + 1 + … + 1، وعددهم n + 1.
y[n] = n + 1 , n ≥ 0
7. اكتب الإجابة النهائيةالـ u[n] بتلم الحالتين (n < 0 صفر، و n ≥ 0 القانون):
y[n] = ((1 − an+1) / (1 − a)) u[n] , a ≠ 1
y[n] = (n + 1) u[n] , a = 1
