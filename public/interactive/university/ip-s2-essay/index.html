Problem 2.14
يعني: S₁ و S₂: 4 و 8 و m-adjacent؟

From the book figure (V = {1}), the two subsets are:

S₁ (cols 2–5)S₂ (cols 6–9)
row 10 0 0 00 0 1 1
row 20 0 1 00 1 0 0
row 30 0 1 01 1 0 0
row 40 1 1 10 0 0 0

The pixels where the subsets meet: S₁ last column = 0, 0, 0, 1 (row 4); S₂ first column = 0, 0, 1, 0 (row 3).

(a) Not 4-adjacent: no pixel of value 1 in S₁ has a horizontal or vertical neighbour of value 1 in S₂ (row 3: 0|1, row 4: 1|0).

(b) 8-adjacent: p = (row 4, col 5) in S₁ and q = (row 3, col 6) in S₂ are both 1 and are diagonal neighbours, so q ∈ N₈(p).

(c) m-adjacent: q ∈ N_D(p) and N₄(p) ∩ N₄(q) = {(row 3, col 5), (row 4, col 6)}, whose values are 0 and 0 (not in V). So S₁ and S₂ are m-adjacent.

Problem 2.31
يعني: أثبت التعابير بـ Venn.

(a) From the book: (A ∩ B) ∪ [(A ∩ C) − (A ∩ B ∩ C)] = A ∩ (B ∪ C).

Left side: (A ∩ C) − (A ∩ B ∩ C) is the part of A ∩ C outside B. Adding A ∩ B gives every point of A that is in B or in C, which is exactly A ∩ (B ∪ C).

(b) and (d) are De Morgan's laws: a point is outside A ∪ B ∪ C exactly when it is outside A, outside B and outside C; a point is outside A ∩ B ∩ C exactly when it is outside at least one of them.

(c) (A ∪ C)ᶜ ∩ B = B ∩ Aᶜ ∩ Cᶜ = the part of B outside A and outside C = (B − A) − C.

Problem 2.32
يعني: اكتب تعبير للمناطق المظللة.

Figure: A = circle, B = triangle, C = rectangle (right half). Reading the shaded regions of the book figure:

  • (a) upper-right of the circle (in A and C, not B) and lower-left of the circle (in A and B, not C): (A ∩ C − B) ∪ (A ∩ B − C)
  • (b) upper-left of the circle (A only) and the part of the triangle inside the rectangle outside the circle: [A − (B ∪ C)] ∪ [(B ∩ C) − A]
  • (c) everything in the triangle or rectangle except the circle: (B ∪ C) − A
  • (d) everything except the regions that are in B and in A or C: (A ∪ B ∪ C) − [B ∩ (A ∪ C)]

(These follow my reading of the shading in the book figure; check the figure in the book, p. 116.)
