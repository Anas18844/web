LSI Systems و Convolution

لو الـ system خطي وثابت مع الوقت، يبقى h[n] لوحدها بتوصفه بالكامل، والخرج بييجي من Convolution. ده أهم درس في الامتحان.

الجزء 1

باقي خصايص الـ System

الـ LSI = Linear + Shift-Invariant. مثال: y[n] = 0.5x[n] + 0.5x[n−1].

الخاصيةالمعنىلو LSI
Causalمفيش مستقبل في xh[n] = 0 for n < 0
BIBO Stableدخل محدود ← خرج محدودΣ|h[n]| < ∞
Invertibleترجع x من y بشكل وحيدلاقي inverse أو دخلين بنفس الخرج
تريك Causal: جرب n سالبة. x[|n|] عند n = −1 عايزة x[1]، يبقى non-causal. ونفس الفكرة مع x[n²−n] عند n = −1.
تريك Stable: لإثبات عدم الاستقرار هات دخل محدود خرجه بيكبر، زي x = u[n]. والمجمّع Σx(k) unstable لأن خرجه n+1.
تريك Invertible: لنفي الخاصية هات دخلين مختلفين بنفس الخرج. x[n] وx[n]+c بيدوا نفس الفرق في x[n]−x[n−1]. ولإثباتها اكتب الـ inverse: معكوس Σx(k) هو y[n] − y[n−1].
الجزء 2

الـ Convolution

كل عينة في x بتشغّل نسخة من h، مزاحة لمكانها ومضروبة في قيمتها. والخرج هو مجموع النسخ دي.
y[n] = x[n] * h[n] = Σₖ x[k] h[n−k]
  1. اكتب القيم ومعاها الـ indices.
  2. بداية الخرج = بداية x + بداية h.
  3. الطول: Lᵧ = Lₓ + Lₕ − 1.
  4. احسب كل y[n]: مجموع كل حاصل ضرب مجموع indices بتاعه = n.
مثال محلول

x = [1, 2] وh = [3, 4]:

y[0] = 1×3 = 3

y[1] = 1×4 + 2×3 = 10

y[2] = 2×4 = 8

تريك السرعة (الضرب بدون حمل): اعمل جدول، x فوق وh على الجنب، واضرب كل خانة، واجمع الأقطار. أسرع طريقة في نص ساعة.
تريك المراجعة: Σy = Σx · Σh. ده بيكشف أي غلطة حسابية في ثواني.
تريك الـ impulse: x[n] * δ[n−n₀] = x[n−n₀]. فـ h = 2δ[n] − δ[n−1] معناها y[n] = 2x[n] − x[n−1]، من غير أي flip.
فخ: لو الإشارة مبتدية عند n = −1، خد بالك من الـ index. دي أكتر غلطة في الشيت.
جرّب بنفسك: Convolution خطوة بخطوة
الجزء 3

الخصايص والمسائل المغلقة

الخاصيةالقانونالمعنى العملي
Commutativex*h = h*xاختار الأسهل تعكسه
Associative(x*h₁)*h₂ = x*(h₁*h₂)فلاتر ورا بعض (cascade)
Distributivex*(h₁+h₂) = x*h₁ + x*h₂فلاتر جنب بعض (parallel)
إثبات Commutative (1.30)

عوّض l = n−k في الـ sum:

Σₖ x[k]h[n−k] = Σₗ x[n−l]h[l] = h*x

الإشارات اللا نهائية

لما يكون فيه u، حدد الـ limits من شروط الـ steps، وبعدين استخدم الـ geometric series:

Σₖ₌₀ⁿ aᵏ = (1 − aⁿ⁺¹) / (1 − a),   a ≠ 1
مثال محلول

x = aⁿu[n] وh = u[n]: u[k] بتدي k ≥ 0، وu[n−k] بتدي k ≤ n.

y[n] = Σₖ₌₀ⁿ aᵏ = ((1 − aⁿ⁺¹)/(1 − a)) u[n]

ولو a = 1: y[n] = (n+1)u[n].

تريك 1.34: لما تكون إشارة محدودة، قسّم حالات: n < 0، ووسط الفترة، وبعد نهايتها. والـ limit العليا بتبقى الأصغر من n ونهاية الفترة.
الـ Correlation (1.36): مش في السلايدز، بس مطلوب. x ⋆ h = Σ x(k)h(n+k): نفس الـ convolution بس من غير flip لـ h.
تسخين

5 أسئلة سريعة

مسائل بأرقام جديدة

حل بالورقة الأول

1. أوجد y[n] = x[n] * h[n] لـ x[−1]=1, x[0]=2 وh[1]=3, h[2]=1.
البداية −1 + 1 = 0، والطول 3.
y[0] = 1×3 = 3، y[1] = 1×1 + 2×3 = 7، y[2] = 2×1 = 2.
y = {3, 7, 2}. مراجعة: 12 = 3 × 4 ✓
2. أوجد [u[n] − u[n−3]] * [u[n] − u[n−2]]، واكتبها piecewise.
{1,1,1} * {1,1} = {1, 2, 2, 1} عند n = 0…3.
Piecewise: n+1 لـ 0≤n≤1، و2 عند n=2، و1 عند n=3، و0 غير كده.
3. أوجد (½)ⁿu[n] * u[n].
y[n] = Σₖ₌₀ⁿ (½)ᵏ = 2(1 − (½)ⁿ⁺¹)u[n] = (2 − (½)ⁿ)u[n]
4. h[n] = (0.5)ⁿu[n]: هل الـ system causal و stable؟
Causal لأن h = 0 لـ n < 0. وstable لأن Σ(0.5)ⁿ = 2 < ∞.
5. هل y[n] = x[n²] causal؟
لأ: عند n = 2، الخرج عايز x[4]، وده مستقبل.

5 سطور تراجعهم قبل الامتحان

  1. LSI معناها h[n] بتوصف الـ system كله.
  2. Causal: h[n] = 0 لـ n < 0. Stable: Σ|h| < ∞.
  3. y[n] = Σ x[k]h[n−k]، والبداية مجموع البدايتين، والطول Lₓ + Lₕ − 1.
  4. استخدم جدول الضرب وراجع بـ Σy = Σx·Σh.
  5. الإشارات اللا نهائية: حدد limits من الـ steps وبعدين geometric series.
