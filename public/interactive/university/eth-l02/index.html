Ethical Hackers

مين الـ hackers، وأنواعهم الخمسة، وقواعد السلوك، ولغة الـ hacking، وخطوات الهجوم.

الشرح

افهم الأول

مين الـ Ethical Hacker؟

  • شغال بعقد أو تعيين عشان يختبر الأمان.
  • نفس مهارات الـ hacker، بس بإذن صاحب النظام.
  • العقد بيحدد المسموح والممنوع.

الأنواع الخمسة

النوعالكلمة المفتاحية
Script Kiddiesتدريب قليل، وأدوات بسيطة، ومش فاهمين بيعملوا إيه
White-Hatمش هيأذوا. وهم ethical hackers أو Pen testers
Gray-Hatبين الخير والشر. قرروا يتصلحوا، بس لسه مش موثوق فيهم
Black-Hatالوحشين، ضد القانون، قريبين من الجريمة
Suicideعايزين يثبتوا نقطة، ومش خايفين من السجن
سؤال "الأخطر": Black-hat. و"ميثاق أخلاقي": White. و"أدوات بسيطة": Script kiddies.

خطوات الهجوم بالترتيب

  1. Footprinting: جمع معلومات passive.
  2. Scanning: تعامل مباشر مع الهدف.
  3. Enumeration: تفاصيل: usernames و groups.
  4. System hacking: تنفيذ الهجوم.
  5. Escalation of privilege: صلاحيات أعلى.
  6. Covering tracks: مسح الـ logs.
  7. Planting of backdoors: باب للرجوع.

Code of Conduct (أهم النقط)

  • سرية المعلومات.
  • حماية الملكية الفكرية.
  • مفيش برامج مسروقة، ولا تعامل مع malicious hackers.
  • كل pen testing لازم يكون authorized.
