تصنيف الـ Discrete-Time Signals

قبل ما نعدل الإشارة لازم نوصفها بـ 3 أسئلة: قيمها فين؟ بتتكرر؟ متماثلة؟

الجزء 1

الـ Signal Duration

النوعالشرطمثال
Finite-lengthصفر برة فترة محددةu[n] − u[n−4]
Right-sidedصفر قبل n₀u[n+1]
Left-sidedصفر بعد n₀u[−n−3]
Two-sidedلا نهائية من الناحيتين(1/2)ⁿ
مثال محلول

x[n] = u[n−2] − u[n−6]: الفرق بيساوي 1 من 2 لحد 5، وصفر برة كده. يبقى finite-length بـ support [2, 5].

تريك: u[−n−3] اسأل نفسك الجوة ≥ 0 إمتى: −n−3 ≥ 0 يعني n ≤ −3، يبقى left-sided.
الجزء 2

الـ Periodicity

الإشارة periodic لو بتتكرر بعد عدد صحيح من العينات:

x(n + N) = x(n)   for all n,   N > 0 integer

أصغر N هو الـ fundamental period. ولـ cos(ω₀n) بنحل:

ω₀N = 2πk  ⇒  N = 2πk / ω₀
مثال محلول

cos(πn/2): πN/2 = 2πk، يعني N = 4k، وأصغر قيمة N = 4.

تريك: لو ω₀ فيها π، يبقى ينفع نلاقي N. ولو من غير π زي sin(0.2n)، يبقى aperiodic، لأن π مش كسر.
مجموع أو ضرب إشارتين: N = N₁N₂ / gcd(N₁, N₂)، وده هو الـ LCM.
جرّب بنفسك: cos(ω₀n) بـ ω₀ = pπ/q
الجزء 3

الـ Symmetry

Even: x(n) = x(−n). Odd: x(n) = −x(−n)، وبالتالي لازم x(0) = 0.

وأي إشارة بتتقسم لجزء even وجزء odd:

xₑ(n) = ½[x(n) + x(−n)]     xₒ(n) = ½[x(n) − x(−n)]
مثال محلول

x = {1, 2, 3} عند n = −1, 0, 1. المقلوبة x(−n) = {3, 2, 1}.

يبقى xₑ = {2, 2, 2} وxₒ = {−1, 0, 1}.

تريك: راجع دايمًا إن xₑ + xₒ = x، وإن xₒ(0) = 0.
ربط زي الأرقام: even × even = even، وodd × odd = even، وeven × odd = odd.

إضافة من الأسايمنت: Conjugate Symmetry

مش في السلايدز، بس مطلوبة في 1.5 و1.6. نفس الفكرة للإشارات الـ complex، مع conjugate:

xₑ(n) = ½[x(n) + x*(−n)]

5 أسئلة سريعة

مسائل بأرقام جديدة

حل بالورقة الأول

1. أوجد الـ fundamental period لـ x[n] = cos(πn/4) + sin(πn/6).
N₁ = 8 وN₂ = 12، وgcd = 4، يبقى N = 96/4 = 24.
2. هل x[n] = cos(3πn/4) periodic؟
3πN/4 = 2πk، يعني N = 8k/3. أصغر قيمة صحيحة عند k = 3، يبقى N = 8.
3. أوجد xₑ وxₒ لـ x = {2, 5, 1} عند n = −1, 0, 1.
x(−n) = {1, 5, 2}، يبقى xₑ = {1.5, 5, 1.5} وxₒ = {0.5, 0, −0.5}.
4. لو x₁ وx₂ الاتنين odd، إيه نوع y(n) = x₁(n)x₂(n)؟ أثبت.
y(−n) = x₁(−n)x₂(−n) = (−x₁(n))(−x₂(n)) = y(n)، يبقى even.

5 سطور تراجعهم قبل الامتحان

  1. Duration: Finite وRight-sided وLeft-sided وTwo-sided.
  2. Periodic لو N = 2πk/ω₀ طلع صحيح، ومن غير π تبقى aperiodic.
  3. مجموع إشارتين: N = N₁N₂/gcd(N₁,N₂).
  4. xₑ = ½[x(n)+x(−n)] وxₒ = ½[x(n)−x(−n)].
  5. Odd معناها x(0) = 0، وراجع xₑ + xₒ = x.
