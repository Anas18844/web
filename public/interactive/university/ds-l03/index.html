الموديل الخطي: The Linear Model I

الخط المستقيم بشكل جد: نختار الصفات، ونصنف، ونتوقع رقم في خطوة واحدة، ونعمل منه حدود مش خطية.

الجزء 1 من 7

الـ Input Representation: نختار الصفات

نبدأ بداتا حقيقية: أرقام مكتوبة بخط اليد (مكتب البريد).

كل رقم صورة 16 × 16، يعني 256 pixel.

لو خدنا الـ pixels زي ما هي (raw input)

x = (x₀, x₁, …, x₂₅₆)، و x₀ = 1.

يعني الموديل محتاج 257 وزن: w₀ … w₂₅₆. كتير جدًا.

الحل: Features

نطلّع معلومة مفيدة بدل الـ pixels. مثلًا صفتين:

  • x₁: intensity، الرقم متغطي حبر قد إيه.
  • x₂: symmetry، الرقم متماثل قد إيه.

كده x = (x₀, x₁, x₂)، والموديل محتاج 3 أوزان بس.

الرقم 1 حبره قليل ومتماثل. والرقم 5 حبره أكتر ومش متماثل. فالصفتين دول بيفرقوا بينهم.
فخ: عدد الأوزان = d + 1 بسبب x₀. الـ 256 pixel = 257 وزن.

الـ Linear Classification: الـ PLA والـ Pocket

نشغّل الـ PLA على داتا الأرقام الحقيقية. إيه اللي بيحصل؟

الداتا الحقيقية مش linearly separable. فيه نقط متلخبطة.

  • الـ PLA مش بيقف.
  • الـ Ein بيطلع وينزل بشكل عشوائي.
  • لو وقفناه عند iteration معينة، ممكن تكون وحشة.

الحل: الـ Pocket Algorithm

الفكرة: زي ما اسمه، جيب بنشيل فيه أحسن حل.

  1. شغّل الـ PLA عادي.
  2. بعد كل iteration احسب Ein.
  3. لو أحسن من اللي في الجيب، حط w الجديدة في الجيب.
  4. في الآخر، رجّع اللي في الجيب.
الـ PLA بيرجّع آخر w. والـ Pocket بيرجّع أحسن w شافها.
معمل: PLA ضد Pocket على داتا مش separable

البرتقالي Ein بتاع الـ PLA، والأزرق بتاع الـ Pocket. لاحظ إن الأزرق عمره ما بيطلع.

الـ Linear Regression: الخرج رقم

نرجع للبنك.

  • Classification: نوافق ولا لأ؟ (yes/no)
  • Regression: نديله credit line قد إيه؟ (رقم بالدولار)
regression ≡ real-valued output، يعني الخرج رقم حقيقي.

الموديل

نفس المجموع، بس من غير sign:

h(x) = Σᵢ₌₀ᵈ wᵢxᵢ = wᵀx

والداتا: (x₁,y₁) … (xN,yN)، و yₙ هو الـ credit line اللي حدده موظف البنك.

نقيس الغلط إزاي؟ بالأرقام

عندنا 3 عملاء و h جاهزة:

nh(xₙ)yₙh − y(h − y)²

Ein = (1 + 4 + 1) / 3 = 2.

القاعدة: Squared error

Ein(h) = (1/N) Σₙ₌₁ᴺ (h(xₙ) − yₙ)²

وليه تربيع؟ عشان الغلط الموجب والسالب ما يلغوش بعض، والغلط الكبير ياخد عقاب أكبر.

فخ: اقسم على N. وربّع كل فرق قبل ما تجمع.

نكتب Ein بالمصفوفات

بدل ما نجمع واحد واحد، نحط كل حاجة في مصفوفة.

الـ X والـ y

  • X: كل صف عميل، x₁ᵀ, x₂ᵀ, …, x_Nᵀ.
  • y: عمود فيه y₁, …, yN.
مثال: 3 عملاء بصفة واحدة
xy

لازم نضيف عمود x₀ = 1:

X = [1 1 ; 1 2 ; 1 3] , y = [1 ; 3 ; 4]

المعادلة بالمصفوفات

Ein(w) = (1/N) ‖Xw − y‖²

Xw هو كل التوقعات مرة واحدة. و Xw − y كل الأخطاء. والـ ‖·‖² مجموع مربعاتها.

نلاقي أحسن w: الـ Pseudo-inverse

عايزين w اللي تخلي Ein أقل حاجة.

الاشتقاق (ممكن يطلبه مقالي)

  1. نبدأ من: Ein(w) = (1/N)‖Xw − y‖²
  2. نفاضل ونساوي بصفر: ∇Ein(w) = (2/N) Xᵀ(Xw − y) = 0
  3. نفك القوس: XᵀXw = Xᵀy
  4. نضرب في المعكوس: w = (XᵀX)⁻¹Xᵀy
  5. نسمّي X† = (XᵀX)⁻¹Xᵀ، فيبقى w = X†y.
X† اسمها pseudo-inverse. والحل في خطوة واحدة (one-step)، مش iterations زي الـ PLA.

الـ Algorithm في 3 خطوات

  1. كوّن X و y من الداتا.
  2. احسب X† = (XᵀX)⁻¹Xᵀ.
  3. رجّع w = X†y.

مثال كامل بالأرقام

النقط: (1, 1) و (2, 3) و (3, 4)
  1. XᵀX = [3 6 ; 6 14]
    (N، و Σx ، و Σx، و Σx²)
  2. Xᵀy = [8 ; 19]
    (Σy = 8، و Σxy = 1 + 6 + 12 = 19)
  3. المحدد: 3 × 14 − 6 × 6 = 6
  4. المعكوس: (1/6) [14 −6 ; −6 3]
  5. w = (1/6) [14(8) − 6(19) ; −6(8) + 3(19)] = (1/6)[−2 ; 9]
  6. النتيجة: w₀ = −1/3 و w₁ = 3/2

يعني الخط: h(x) = −1/3 + 1.5x.

ولو حسبنا الغلط: Ein = 1/18 ≈ 0.056.

قانون سريع لصفة واحدة: XᵀX = [N Σx ; Σx Σx²] و Xᵀy = [Σy ; Σxy]. ومعكوس مصفوفة 2×2: اقلب القطر، وغيّر إشارة الباقي، واقسم على المحدد.
معمل: اكتب نقطك وشوف الحل

نستخدم الـ Regression في الـ Classification

فكرة ذكية: الـ +1 والـ −1 أرقام حقيقية برضه.

يعني نقدر نستخدم linear regression على داتا فيها y = ±1.

  1. نشغّل regression عشان wᵀxₙ ≈ yₙ = ±1.
  2. غالبًا sign(wᵀxₙ) هيتفق مع yₙ.
  3. نستخدم w دي نقطة بداية للـ PLA أو الـ Pocket.
Linear regression بيدي good initial weights للـ classification، في خطوة واحدة.

مثال

لو w = [0.1, 0.5, −0.2] و x = (2, 1):

wᵀx = 0.1 + 1 − 0.2 = 0.9، فالـ sign = +1.

الـ Nonlinear Transformation

الخط مش كفاية

لو الأزرق جوه دايرة والأحمر برة، مفيش خط يفصلهم.

ومثال تاني: الـ credit line بيتأثر بـ "سنين الإقامة" بشكل مش خطي. الأحسن نسأل: [[xᵢ < 1]] و [[xᵢ > 5]].

السر: Linear in what?

المعادلة Σ wᵢxᵢ خطية في حاجتين: في x، وفي w.

الـ algorithms بتشتغل بسبب إنها خطية في الأوزان w. مش لازم تكون خطية في x.

يبقى نغيّر x نفسها

  1. نحوّل كل نقطة: (x₁, x₂) → Φ → (x₁², x₂²)
  2. نشغّل الموديل الخطي عادي في الفضاء الجديد.
  3. الخط هناك بيبقى دايرة هنا.
مثال بالأرقام

h(x) = sign(0.6 − x₁² − x₂²)، يعني w̃ = [0.6, −1, −1] في الفضاء الجديد.

xz = (x₁², x₂²)0.6 − z₁ − z₂h

(1, 0)(1, 0)−0.4−1

أسئلة مقالية

اكتب الإجابة في ورقة الأول

ده الشكل اللي الدكتور ممكن يسأل بيه. اكتب، وبعدين قارن بالإجابة النموذجية.

1. اشرح يعني إيه input representation، بمثال الأرقام.

Raw input: 256 pixel، يعني 257 وزن. بدل كده نستخرج features زي intensity و symmetry، فنحتاج 3 أوزان بس.

2. قارن بين الـ PLA والـ Pocket.

الـ PLA بيرجع آخر w، وعلى داتا مش separable مش بيقف و Ein بيتذبذب. الـ Pocket بيشغل PLA ويحتفظ بأحسن w حسب Ein، وبيرجعها.

3. قارن بين Classification و Regression في مثال البنك.

Classification: موافقة yes/no، و h = sign(wᵀx). Regression: credit line رقم، و h = wᵀx، والخطأ squared error.

4. اكتب Ein بالجمع وبالمصفوفات.

Ein = (1/N) Σ (wᵀxₙ − yₙ)² = (1/N)‖Xw − y‖²، حيث X صفوفها xₙᵀ و y عمود.

5. اشتق حل الـ linear regression.

∇Ein = (2/N)Xᵀ(Xw − y) = 0 ← XᵀXw = Xᵀy ← w = (XᵀX)⁻¹Xᵀy = X†y.

6. اكتب الـ linear regression algorithm.

(1) كوّن X و y. (2) احسب X† = (XᵀX)⁻¹Xᵀ. (3) رجّع w = X†y.

7. ليه linear regression مفيد للـ classification؟

لأن ±1 أرقام حقيقية، فبنطلع w بحيث wᵀxₙ ≈ yₙ، و sign(wᵀx) غالبًا صح. وبتبقى good initial weights للـ PLA/Pocket.

8. اشرح الـ nonlinear transformation، وLinear in what؟

الـ algorithms بتعتمد على الخطية في w مش x. فبنحول (x₁,x₂) → (x₁²,x₂²) بـ Φ، ونشغل الموديل الخطي في الفضاء الجديد، فالخط هناك يبقى حد غير خطي في x.

الخلاصة

السطور اللي تراجعها الصبح

  1. Features: بدل 257 وزن، 3 أوزان (intensity و symmetry).
  2. الـ PLA آخر w، والـ Pocket أحسن w حسب Ein.
  3. Regression: h = wᵀx، و Ein = (1/N)‖Xw − y‖².
  4. w = X†y و X† = (XᵀX)⁻¹Xᵀ، وأبعادها (d+1) × N.
  5. بنستخدم regression كـ good initial weights للـ classification.
  6. الموديل linear في w. فنقدر نعمل Φ(x₁,x₂) = (x₁²,x₂²).
