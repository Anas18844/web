🧪 جرّب بنفسك: Sampling و Quantization

حرّك الماوس على الصورة تشوف قيمة البكسل

👈 جرّب: خلي الدرجات 256 وقلّل المربعات لـ 8 → الصورة بقت بلوكات (sampling قليل). رجّع المربعات 256 وخلي الدرجات 2 → الصورة بقت أبيض وأسود بس (quantization قليل).

أشهر رقم: 8 bits = 2⁸ = 256 درجة من 0 (أسود) لـ 255 (أبيض). ولو 16 bits يبقى 65,536 درجة.

④ فخ الـ 255 (The uint8 trap)

الكوباية الصغيرة (uint8) لو صبّيت فيها أكتر من 255، الزيادة بتدلق وتفضل مليانة لحد الحافة: 255. ولو شِلت منها أكتر من اللي فيها، تفضل فاضية: 0. وعمرها ما "تلف" وتبدأ من الأول. الحكاية دي اسمها Saturation.

⑦ تدريب: من السهل للصعب

الفكرة الكبيرة: كل حاجة هنا هي g(x,y) = T[f(x,y)]. لو T بتبص على البكسل لوحده = point operation (contrast، gamma، histogram). لو بتبص على نافذة حواليه = neighborhood / spatial filtering (smoothing، median، sharpening).

1. Point vs Neighborhood operations

2. imadjust: أداة الـ contrast

g = imadjust(f, [low_in high_in], [low_out high_out], gamma);
g = imadjust(f, stretchlim(f), []);    % limits أوتوماتيك
g = imadjust(f, [0 1], [1 0]);         % negative
g = imadjust(f, [ ], [ ], 0.5);        % gamma = 0.5
g = imadjust(f, [0.5 0.75], [0 1]);    % Ex 3.1: مدّ 0.5-0.75 على المدى كله
  • 4 inputs: الصورة، input range، output range، gamma (الـ narration قالت 5، غلط).
  • الـ ranges دايمًا كسور من 0 لـ 1 مهما كان الـ class. في uint8 الـ 0.5 = 127.5.
  • [ ] = الـ default [0 1].
  • اللي تحت low_in بيبقى low_out، واللي فوق high_in بيبقى high_out، والوسط بيتمد خطيًا (لو gamma = 1).
  • gamma < 1 يفتّح الـ mid-tones (المنحنى بيتقوّس لفوق). gamma > 1 يغمّقها.
  • stretchlim(f) بيلاقي الـ limits لوحده، وبيتجاهل أغمق 1% وأفتح 1% من البكسلات.
  • طرق تانية للـ negative: imcomplement(f)، أو 255 - f لـ uint8. مثال: بكسل 64 → 191.

مثال محلول

imadjust(f, [0.5 0.75], [0 1]) على بكسل uint8 قيمته 160:

160/255 = 0.627          % نحوّله لكسر
(0.627 - 0.5) / (0.75 - 0.5) = 0.51   % مكانه جوه الـ input range
0.51 × 255 ≈ 130         % النتيجة
% وأي بكسل ≤ 127 يبقى 0 ، وأي بكسل ≥ 191 يبقى 255

3. Log transform و Contrast stretching

g = im2uint8(mat2gray(log(1 + im2double(f))));    % log transform
g = 1 ./ (1 + (m ./ (im2double(f) + eps)).^E);    % contrast stretching
  • Log transform بيضغط dynamic range كبير جدًا (زي Fourier spectrum من 0 لـ 1,500,000 → حوالي 0 لـ 6) عشان التفاصيل الغامقة تبان. Inverse log بيعمل العكس.
  • الـ 1 + جوه الـ log عشان نتجنب log(0).
  • log في MATLAB = الطبيعي (ln). log10 = أساس 10.
  • Contrast stretching (S-curve): m = الـ threshold (بكسل قيمته m يطلع 0.5)، و E = الميل. E كبير جدًا → المنحنى يبقى step = thresholding.
  • eps = رقم صغير جدًا عشان نمنع القسمة على صفر لما البكسل = 0.
  • دايمًا حوّل لـ double (im2double) قبل المعادلات دي، ورجّع بـ im2uint8 أو mat2gray.
مش built-in: intrans و gscale و tofloat ملفات M-file كاتبها الكتاب. لو MATLAB قال Undefined function يبقى مش على الـ path. أما imadjust, stretchlim, imhist, histeq, adapthisteq, imfilter, fspecial, medfilt2, colfilt فدول toolbox حقيقي.

4. Histograms

Histogram = عدد البكسلات عند كل مستوى إضاءة: h(r_k) = n_k. لو قسمت على عدد البكسلات تطلع probabilities:

h = imhist(f);                 % counts
p = imhist(f) / numel(f);      % normalized histogram
bar(imhist(f)); stem(imhist(f));  % طرق رسم (Ex 3.4)
  • صورة غامقة: الـ histogram متكوّم عند 0 (زي صورة Phobos).
  • صورة low-contrast: الـ histogram محشور في شريط ضيق.
  • الـ histogram بيقولك المشكلة قبل ما تلمس أي parameter.
الطريقةالأمربتعمل إيه
Equalizationhisteq(f, 256)بتفرد الـ histogram ناحية uniform باستخدام الـ cumulative distribution (CDF). أوتوماتيك. Point operation.
Matching (Specification)histeq(f, hspec)تجبر الـ output يشبه histogram أنت مصممه. hspec = vector قيمة لكل مستوى (256 لـ uint8)، مش صورة.
Local / CLAHEadapthisteq(f)tile by tile (default 8×8 tiles). ClipLimit (default 0.01) بيحدد قد إيه الـ contrast يزيد عشان الـ noise في المناطق المسطحة ما يتفجرش.
خلي بالك: histeq(f) من غير رقم = 64 مستوى. اكتب 256 لو عايز 8-bit كاملة. والـ equalization بيطلع histogram تقريبًا flat مش flat بالظبط، لأن المستويات discrete. ClipLimit أكبر = contrast أكتر و noise أكتر.

ليه global equalization ممكن يبوّظ؟ لأنه بيكبّر الـ noise في المناطق المسطحة. الـ adapthisteq بيحل ده بالـ tiles والـ clip.

5. Spatial Filtering: الميكانيكا

Kernel (أو mask أو filter) = مصفوفة أوزان صغيرة (3×3، 5×5). لكل بكسل:

  1. حط الـ kernel فوق الجيران، والـ origin (center) فوق البكسل.
  2. اضرب كل وزن في البكسل اللي تحته.
  3. اجمع كله واكتب الناتج في الـ output.
  4. زق بكسل وكرر.

Correlation vs Convolution

  • Correlation: الـ kernel زي ما هو. الناتج أعلى حاجة لما الـ kernel يطابق الصورة.
  • Convolution: نلف الـ kernel 180° الأول. دي العملية اللي ورا linear systems theory.
  • imfilter بيعمل correlation by default. ضيف 'conv' للـ convolution.
  • الـ symmetric kernels (average، Laplacian، Gaussian) بتدّي نفس النتيجة في الاتنين، وعشان كده الفرق ساعات مش باين.
g = imfilter(f, w);                       % correlation + zero padding
g = imfilter(f, w, 'replicate');          % border handling
g = imfilter(f, w, 'conv', 'symmetric');  % convolution
w = fspecial('average', [3 3]);           % ones(3)/9
w = fspecial('laplacian', 0.2);           % Laplacian
w = fspecial('sobel');                    % edges

Padding (الحدود)

عند حرف الصورة الـ kernel محتاج بكسلات برا الصورة:

الخياربيعمل إيه
default (zero padding)أصفار برا → إطار غامق
'replicate'يكرر قيمة الحرف
'symmetric'مراية للصورة عند الحرف
'circular'يلف (كأن الصورة بتتكرر)

الـ padding بيخلي الـ output نفس حجم الـ input.

Output class: imfilter بيرجّع نفس class الـ input. لو f uint8 وعملت Laplacian أو Sobel، أي قيمة سالبة تتقص لـ 0 وأي حاجة فوق 255 تبقى 255. حوّل لـ double الأول (im2double أو tofloat) لما الـ kernel فيه أوزان سالبة.

مجموع أوزان الـ kernel: smoothing = 1 (الإضاءة العامة ما تتغيرش). derivative (Laplacian، Sobel) = 0 (المنطقة المسطحة تطلع 0).

مثال محلول: average 3×3

neighborhood = [10 20 30; 40 50 60; 70 80 90]
w = ones(3)/9
output = (10+20+30+40+50+60+70+80+90)/9 = 450/9 = 50

6. Smoothing و Median filter

  • Averaging (box) filter: بيشيل noise بس بيشيل تفاصيل كمان. kernel أكبر = blur أقوى (9×9 خفيف، 25×25 تقيل). ده الـ trade-off كله.
  • Weighted average: السنتر وزنه أكبر → blur أقل لنفس إزالة الـ noise.
  • Median filter = nonlinear: رتّب قيم الجيران وخد اللي في النص. بيشيل salt-and-pepper (impulse) noise ويحافظ على الـ edges. وعمره ما يطلع قيمة مش موجودة في الجيران.

مثال محلول

الجيران:  3, 7, 200, 5, 6, 4, 8, 5, 9
مترتبين:  3, 4, 5, 5, [6], 7, 8, 9, 200
median  = 6
average = 247/9 ≈ 27.4   ← بكسل noise واحد (200) سحب المتوسط

ليه الـ median nonlinear؟ لأنه مش weighted sum للجيران، فمينفعش يتكتب kernel لـ imfilter.

g = medfilt2(f, [3 3]);                  % zero padding default
g = medfilt2(f, [3 3], 'symmetric');     % من غير إطار غامق
g = uint8(colfilt(f, [3 3], 'sliding', @median));          % Ex 3.9
s = colfilt(f, [5 5], 'sliding', @(x) std(x, 1, 1));       % local std

colfilt بيطبّق أي function على كل neighborhood (@median, @max, @std). في std(x,1,1): أول 1 = normalize بـ N، وتاني 1 = اشتغل على الأعمدة.

7. Sharpening

  • Laplacian (second derivative): بيرد على التغيير السريع: edges وتفاصيل دقيقة. المنطقة المسطحة = 0.
  • Gradient (first derivative، زي Sobel): لاكتشاف الـ edges. Sobel = kernel أفقي + kernel رأسي، بيتجمعوا في magnitude.

Laplacian sharpening: قاعدة الإشارة

Sign rule: السنتر سالب (زي fspecial('laplacian') و [0 1 0; 1 -4 1; 0 1 0]) → g = f − lap. السنتر موجب → g = f + lap.
w   = fspecial('laplacian', 0);       % [0 1 0; 1 -4 1; 0 1 0]
lap = imfilter(im2double(f), w, 'replicate');
g   = im2double(f) - lap;             % السنتر سالب → نطرح

مثال: جيران [10 10 10; 10 50 10; 10 10 10] مع [0 1 0; 1 -4 1; 0 1 0]: 10+10+10+10 − 4×50 = −160. في uint8 تبقى 0 (اتقصت)، في double تفضل −160. وبعدين g = 50 − (−160) = 210 → السنتر بقى أوضح.

Unsharp masking و Highboost

بيستخدموا نسخة blurred من الصورة (مش Laplacian):

blurred = imfilter(f, fspecial('average', 5), 'replicate');
mask    = f - blurred;          % التفاصيل بس
g       = f + k * mask;         % k = 1 unsharp ، k > 1 highboost

المعادلة اللي تحفظها: g = f + k·(f − blurred). زرار واحد (k) بيحركك من unsharp لـ highboost.

Top-hat: SE = strel('disk',5,0); g = g - imopen(g, SE); → الـ opening بيشيل الحاجات الفاتحة اللي أصغر من الـ disk، فلما نطرحه يفضل هي بس.

Workflow نموذجي: equalize ← smooth الـ noise ← sharpen التفاصيل ← clip للمدى. مفيش طريقة واحدة بتكسب دايمًا.

8. Fuzzy techniques (باختصار)

  • Membership function μ: بتقول البكسل "تابع قد إيه" لمجموعة (dark / gray / bright) بدل نعم/لا قاطعة.
  • العمليات: union = max، intersection = min، complement = 1 − μ.
  • input membership → rules → output membership، وكل rule بتشتغل بقوة (firing strength)، والنتايج تتجمع (aggregation)، و defuzzification بترجّعها رقم بكسل عادي (crisp).
  • intfuzz (intensity transformation، Ex 3.15)، fuzzfilt (spatial filtering / boundary detection، Ex 3.16: يقارن السنتر بالـ 8 جيران). ميزته: بيشيل noise ويحافظ على الحدود.
