الـ Fundamental Period

نبدأ بأرقام: cos(πn/2)

هنا ω₀ = π/2. عايزين أصغر N صحيح يخلي ω₀N مضاعف لـ 2π.

N = 2πk / ω₀ = 2πk / (π/2) = 4k

أصغر k تدي N صحيح: k = 1، يبقى N = 4.

الخطوات

  1. طلّع ω₀ (المعامل بتاع n).
  2. احسب 2π / ω₀.
  3. لو كسر، بسّطه واضرب في k لحد ما يبقى صحيح.
  4. لو فيه π مش بتروح، يبقى aperiodic.
  5. لو إشارتين جمع، N = lcm(N₁, N₂).
تريك: لو ω₀ من غير π، زي sin(0.2n): يبقى N = 2πk/0.2 = 10πk، ودي مش صحيحة أبدًا، فهي aperiodic.

شكل الإثبات في الامتحان: y[n] = x[n−1]

Shift-invariance

1. Let x₁[n] = x[n−n₀].

2. T{x₁} = x₁[n−1] = x[n−1−n₀].

3. y[n−n₀] = x[n−n₀−1].

4. They are equal, so the system is shift-invariant.

Linearity

1. T{ax₁ + bx₂} = ax₁[n−1] + bx₂[n−1].

2. aT{x₁} + bT{x₂} = ax₁[n−1] + bx₂[n−1].

3. They are equal, so the system is linear.

النتيجة: y = {3, 10, 8} عند n = 0, 1, 2.

الخطوات

  1. جدول الضرب.
  2. اجمع القطريات.
  3. البداية: بداية x + بداية h.
  4. الطول: L_y = L_x + L_h − 1.
  5. مراجعة: Σy = Σx · Σh.
تريك الـ impulse: x * δ[n−k] = x[n−k]. يعني لو h = 2δ[n] − δ[n−1]، يبقى y = 2x[n] − x[n−1].

الصيغة اللي تتكتب

y[n] = x[n] * h[n] = Σₖ x[k] h[n−k]

الخواص

  • Commutative: x * h = h * x
  • Associative: (x * h₁) * h₂ = x * (h₁ * h₂)
  • Distributive: x * (h₁ + h₂) = x * h₁ + x * h₂
إثبات Commutative (مسألة 1.30)

y[n] = Σₖ x[k]h[n−k]. Let m = n − k.

y[n] = Σₘ x[n−m]h[m] = h[n] * x[n].

الأسية (شيت C7)

aⁿu[n] * u[n] = ((1 − an+1) / (1 − a)) u[n] لما a ≠ 1.

ولما a = 1: (n+1)u[n].

أسئلة تتكتب بالكلام

1. Define a signal, and state the three characteristics of a sine wave.

A signal is the variation of a physical quantity with respect to one or more independent variables. Amplitude، و Frequency، و Phase.

2. Prove that convolution is commutative.

y = Σₖ x[k]h[n−k]. Let m = n−k: y = Σₘ x[n−m]h[m] = h * x.

3. What makes an LSI system causal and stable?

Causal: h[n] = 0 for n < 0. Stable: Σ|h[n]| < ∞.

4. Why does LSI matter?

سلوكه كله متلخص في h[n]، والخرج لأي دخل y = x * h. وفي التردد: Y = XH.

5. Show that y[n] = n x[n] is linear but shift-varying.

Linear: T{ax₁+bx₂} = n(ax₁+bx₂) = aT{x₁}+bT{x₂}.

Shift: T{x[n−n₀]} = n x[n−n₀]، و y[n−n₀] = (n−n₀)x[n−n₀]. مختلفين.

6. Give a system additive but not homogeneous, and one homogeneous but not additive.

Additive بس: y = Re{x}. Homogeneous بس: y = x²[n]/x[n−1].
