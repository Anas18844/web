الـ Inference والـ Prompts

Inference means running the model and generating text.
Prompts can have demonstrations (= examples). Chain of Thought: give examples of reasoning in the demonstration. LLMs usually have a system prompt, automatically and silently concatenated to a user prompt. System prompts can be long; 1700 words for Claude Opus 4.
  • Prompt: سؤال أو أمر.
  • Demonstrations: أمثلة جوه الـ prompt (1 demonstration).
  • Chain of Thought: أمثلة فيها خطوات التفكير.
  • System prompt: بيتحط قبل كلام المستخدم أوتوماتيك ومن غير ما يبان، وممكن يبقى طويل (1700 كلمة لـ Claude Opus 4).
  • افتكر: كله في الآخر conditional generation.

الـ In-context Learning والـ Agents

Pretraining sets language model weights via gradient descent. Prompting just changes the context and the activations in the network; no parameters change. We call this in-context learning—learning that improves model performance but does not update parameters.
An agent: an LLM that can act in the world, calling a search engine, a calendar, a python program, a database, an API. It does this having tokens for actions: SEARCH(), CALENDAR(), CALCULATOR().
ReAct: prompt the LLM to generate actions interleaved with reasoning traces.

التقييم

How to make an LLM multilingual? Just throw all the languages data in a big file and pretrain on it! (FineWeb2: 1000 languages, 5 billion documents).
Evaluating accuracy: did the LLM get the right answer? Example: MMLU. Evaluating subjective tasks: Human-as-Judge or LLM-as-a-Judge; evaluations can be single or pairwise. Other factors: size, energy usage (kWh or kg of CO2), fairness.
  • Multilingual: نحط كل اللغات ونعمل pretraining. FineWeb2 فيه 1000 لغة.
  • Accuracy: إجابة واحدة صح، زي sentiment أو 457 + 3 = 460. و MMLU benchmark.
  • Word prediction accuracy: الموديل بياخد credit بنسبة الاحتمال اللي ادّاه للكلمة الصح.
  • Subjective (ترجمة أو شعر): Human-as-Judge بـ rubric، أو LLM-as-a-Judge، وفيه single أو pairwise.
  • عوامل تانية: الحجم، والطاقة (kWh و CO₂)، والـ fairness (bias و stereotypes).

الـ Safety والـ Alignment

Alignment is the goal of getting LMs to avoid harms by acting in ways that align with human needs and values. The word "alignment" is very underspecified (Whose values? What happens if values conflict?).
Two kinds of harms: User-level harms, Societal-level harms.
Mitigating harms: value-sensitive design, post-training and preference alignment, Constitutional AI. But alignment is a very hard and unsolved problem!
User-levelSocietal-level
Emotional dependence (loneliness)، و De-skilling (critical thinking أقل)، و Sycophancy (بيوافق بدل ما يصحح)، و attacking/discrimination (African American English)، وأداء أضعف مع كبار السن واللهجات وغير الإنجليزي cyber attacks، و fraud، و أسلحة، وأثر بيئي (طاقة ومياه)، وتركيز الثروة والسلطة، و job displacement، و existential risk

Limitations: often wrong، و expensive، و overconfident، و poorly calibrated (الدقة الحقيقية مش زي الاحتمال اللي بيديه). و Frankenstein: بناء agents من غير مسؤولية ممكن يوصّل لمأساة.
