ليه لغات البرمجة بتتطور؟

أي لغة جديدة بتظهر لسببين: تكنولوجيا جديدة، أو مشكلة جديدة في مجال معين.

في الأول: كل لغة لمشكلة

FORTRAN (1957، IBM)

اسمها من FORmula TRANslation.

  • المجال: Scientific computing.
  • أول high-level language واسعة الانتشار.
  • بتستخدم الرموز الرياضية.
  • بقت أساس الـ high-performance computing.
COBOL (1959، Grace Hopper)

اسمها Common Business-Oriented Language.

  • المجال: Business data processing.
  • أول لغة موجهة للبيزنس.
  • Syntax شبه الإنجليزي.
  • الكود بيوثق نفسه (self-documentation).

أهداف اللغة: 5 مبادئ

كل لغة بتتصمم عشان تحقق أهداف. الأهداف دي بتحدد الـ syntax والـ semantics ومناسبة اللغة للشغل.

المبدأمعناهبيتحقق بإيه
Readabilityالكود سهل يتفهم للبني آدمClear syntax، و intuitive naming، و structured constructs
Reliabilityأخطاء أقل وسلوك متوقعStrong typing، و robust error handling، و memory safety
Efficiencyاستغلال موارد الجهازLow-level control، و native code compilation، و minimal runtime overhead
Portabilityيشتغل على أجهزة وأنظمة مختلفةStandardized specifications، و virtual machines، و multi-architecture compilers
Expressivenessأفكار معقدة في كود قليلConcise syntax، و rich abstractions، و enhanced productivity
الخمسة مش بييجوا مع بعض. المصمم بيوازن بينهم حسب الـ use case.
فخ: Strong typing تبع Reliability، مش Readability. و Virtual machines تبع Portability، مش Efficiency.

الـ Trade-offs ومثلث التصميم

مش ممكن تكسب كل حاجة. فكل لغة بتضحي بحاجة عشان حاجة.

1. Readability vs Performance: Python و C

Python

Clear syntax، و indentation، و dynamic typing، و interpreted.

الـ Readability على حساب الـ performance.

C

Terse syntax، و explicit memory management، و low-level control، و compile to native code.

الـ Performance على حساب الـ readability.

2. Safety vs Flexibility: Rust و C++

Rust

Ownership، و borrow checker في الـ compile time، وبيمنع null pointer dereferences و data races.

عيبها: steeper learning curve.

C++

Flexibility وتحكم كبير، وقوية للـ performance-critical apps.

عيبها: higher risk of memory-related errors.

3. Simplicity vs Expressiveness: Go و Scala

Go

Minimal features، سهلة، و clear syntax.

عيبها: more verbose.

Scala

Rich features بتجمع OOP و FP، و concise code.

عيبها: steep learning curve.

دراسة حالة: Python و Rust و Go

PythonRustGo
الأولويةReadability و simplicityMemory safety without GCSimplicity و concurrency
الميزةIndentation-based blocksSafety at compile time with no runtime overheadGoroutines و channels
التشغيلInterpreted، line by lineCompiled، performanceFast compilation
تفاصيلLarge ecosystem، strong communityStrict ownership، steep learning curveDeveloped at Google، للـ network services و microservices

Rust: 3 حاجات بتمنعها

  • No null pointer dereferences: المتغير لازم يتعمله initialize قبل الاستخدام.
  • No data races: الـ borrow checker بيضمن safe concurrent access.
  • No double-frees: كل قيمة ليها unique owner.
"Readability counts. Code is read much more often than it is written." من Python Enhancement Proposal 20.

نفس الدالة في 3 لغات

# Python
def greet(name):
    return f"Hello {name}"
print(greet("World"))
// Rust
fn greet(name: &str) -> String {
    format!("Hello {}", name)
}
fn main() {
    println!("{}", greet("World"));
}
// Go
package main
import "fmt"
func greet(name string) string {
    return "Hello " + name
}
func main() {
    fmt.Println(greet("World"))
}
تعرف اللغة من الكود: def وفيه indentation: Python. و fn و println!: Rust. و func و fmt.Println: Go.

JavaScript و Elixir والمقارنة

JavaScript: Web's Lingua Franca
  • Early days: simplicity و expressiveness للتطوير السريع.
  • Trade-off: ضحت بـ strict safety و raw performance.
  • Modern era: الـ JIT compilation (V8) حسّن السرعة.
  • Safety: بتتعالج بـ TypeScript وأدوات خارجية.
Elixir: Embracing Concurrency
  • مبنية على Erlang VM (BEAM).
  • "Let It Crash": isolated processes و message passing.
  • Fault tolerance: فشل جزء مش بيوقّع الباقي.
  • أحسن في الـ IO-bound tasks.
  • Telecommunications، و web servers، و real-time systems.
// JavaScript
function greet(name) {
    return "Hello " + name;
}
console.log(greet("World"));

Key Insights من سلايد المقارنة

  • Python: ممتازة في readability، وبتضحي بـ safety و performance.
  • Rust: بتقدم memory safety و performance على الـ readability السريعة.
  • Go: بتوازن بين simplicity و readability و high performance.
JavaScript تطورت ناحية رأس Performance، مع الحفاظ على Simplicity و Expressiveness.
