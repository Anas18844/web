مثال

Downsample: x = {5,1,4,2,7,3}، وx[2n] بتاخد 0 و2 و4: {5, 4, 7}.

Upsample: x = {3,6,2} تبقى {3,0,6,0,2}.

تريك الامتحان (جدول الـ index): في x(4−n) أو x(2n−3) ما تتخيلش. اعمل جدول: كل n، واحسب الجوة، وهات قيمة x. ده بيحل 1.7 كلها.
مثال محلول

x = {2,1,3} عند n = 0,1,2، وy[n] = x[3−n]:

n=1 → x[2]=3   n=2 → x[1]=1   n=3 → x[0]=2

فخ: Reversal بتغير مكان العينة بس، ما بتغيرش إشارتها. ولاحظ إن عنوان السلايدز دي مكتوب عليه Lecture 2 بالغلط.

الجزء 3

الـ System وخصايصه

الـ system T{·} قاعدة بتاخد x[n] وتطلّع y[n].

Memoryless: y بتعتمد على x[n] عند نفس الـ n بس. y[n] = 2x[n] memoryless، وy[n] = x[n] + x[n−1] with memory.

الـ Linearity

Additivity: T{x₁+x₂} = T{x₁}+T{x₂}    Homogeneity: T{cx} = cT{x}

Linear = الاتنين مع بعض:

T{ax₁ + bx₂} = aT{x₁} + bT{x₂}
تريك: لو فيه constant لوحده (زي +1)، يبقى مش linear. ولو x داخل دالة (log، x²، |x|)، غالبًا nonlinear. أما sin(nπ/2) معامل في n، فما بيبوظش الـ linearity.
فخ 1.12: Re{x} additive بس مش homogeneous، لأن c ممكن تكون complex. وكسر زي x(n+1)x(n−1)/x(n) homogeneous بس مش additive.

الـ Shift-Invariance

لو أزحت الدخل، الخرج لازم يتزاح بنفس المقدار. والاختبار خطوتين:

  1. عوّض x[n−n₀] في الـ system واحسب y₁[n].
  2. احسب y[n−n₀] (بدّل كل n بـ n−n₀).

لو الاتنين زي بعض، يبقى shift-invariant.

مثال محلول

y[n] = x[2n]: y₁[n] = x[2n − n₀]، لكن y[n−n₀] = x[2n − 2n₀]. مختلفين، يبقى shift-varying.

تريك: لو n ظاهرة برة x كمعامل (n·x[n]، x[n]u[n])، أو n مضروبة جوه (x[2n]، x[−n]، x[n²])، يبقى shift-varying.
ربط: الخصايص مستقلة. x² shift-invariant وnonlinear، وx[n]sin(nπ/2) linear وshift-varying.
تسخين

5 أسئلة سريعة

مسائل بأرقام جديدة

حل بالورقة الأول

1. x[n] = (5−n)[u(n) − u(n−5)]. أوجد y[n] = x[2n−2].
x = {5,4,3,2,1} عند n = 0…4. الجدول: n=1 → x[0]=5، وn=2 → x[2]=3، وn=3 → x[4]=1. يبقى y = {5, 3, 1} عند n = 1…3.
2. هل y[n] = 2x[n] + x[n−1] + 3 linear؟
لأ: T{cx} = c(2x[n] + x[n−1]) + 3 مش بتساوي cT{x} = c(2x[n] + x[n−1]) + 3c. والـ additivity برضه بتفشل، لأن الـ 3 بتتحسب مرتين.
3. هل y[n] = x[n]cos(πn) homogeneous، additive، linear، shift-invariant؟
Homogeneous وadditive، يبقى linear. لكن المعامل cos(πn) بيتغير مع n، فهو shift-varying.
4. هل y[n] = x[−n] shift-invariant؟
y₁[n] = x[−n−n₀]، وy[n−n₀] = x[−n+n₀]. مختلفين، يبقى shift-varying.

5 سطور تراجعهم قبل الامتحان

  1. x[n−n₀] يمين، وx[n+n₀] شمال، وx[−n] مراية.
  2. أي تحريك مركب: جدول n ← الجوة ← القيمة.
  3. Linear = Additive + Homogeneous، وأي constant بيكسرها.
  4. Shift-invariant: قارن T{x[n−n₀]} بـ y[n−n₀].
  5. الخصايص مستقلة، فاختبر كل واحدة لوحدها.
