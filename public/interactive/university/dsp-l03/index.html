تحريك الإشارات وخصايص الـ System

هنمشي على مرحلتين: الأولى إزاي نحرك الإشارة، والتانية إزاي نختبر الـ system. وكل فكرة هتبدأ بأرقام، وبعدها القاعدة، وبعدها طريقة حلها في الامتحان.

الجزء 1

الأساس: حاجتين لازم تفرق بينهم

أي إشارة زي جدول فيه عمودين. مثال: x = {2, 1, 3, 0}، وأول قيمة عند n = 0.

n (المكان)0123
x[n] (القيمة)2130
  • n هو المكان، زي رقم الكرسي.
  • x[n] هي القيمة اللي قاعدة على الكرسي.

يعني x[2] = 3 معناها: روح للمكان 2 وهات القيمة اللي فيه.

كل عمليات الدرس نوعين: نوع بيغير الأماكن (الجزء 2 لحد 5)، ونوع بيغير القيم (الجزء 6).
الجزء 2

Shifting: نزيح الإشارة

ناخد x = {1, 2, 3} عند n = 0, 1, 2، ونحسب y[n] = x[n−2]. هنعوّض مكان مكان:

ny[n] = x[n−2]القيمة
1x[−1]0
2x[0]1
3x[1]2
4x[2]3

القيمة 1 كانت عند 0، وبقت عند 2. يعني الإشارة راحت يمين بـ 2. ده اسمه Delay، لأن الإشارة وصلت متأخر.

وبنفس الطريقة، y[n] = x[n+1] بتروح شمال بـ 1، وده اسمه Advance.

فخ: السالب يمين، والموجب شمال. الإحساس بيقول العكس، فلو نسيت عوّض بجدول زي اللي فوق.
الجزء 3

Reversal: نعكس الإشارة

ناخد x[0]=4, x[1]=2, x[2]=7، ونحسب y[n] = x[−n]:

ny[n] = x[−n]القيمة
−2x[2]7
−1x[1]2
0x[0]4

الإشارة اتعكست زي المراية حوالين n = 0.

فخ: اللي بيتعكس هو المكان، مش إشارة القيمة. القيمة 7 بتفضل 7، ومش بتبقى −7.
الجزء 4

Time Scaling: نختار عينات أو نضيف صفار

Downsampling: y[n] = x[2n]

لو x = {5,1,4,2,7,3}:

y[0] = x[0] = 5   y[1] = x[2] = 4   y[2] = x[4] = 7

يعني أخدنا عينة وسبنا عينة، والنتيجة {5, 4, 7}.

Upsampling: نزود صفار

لو x = {3,6,2}، بنحط صفر بين كل عينتين: {3, 0, 6, 0, 2}.

الجزء 5

المسائل المركبة: طريقة ثابتة بـ 3 خطوات

مسألة زي x[4−n] أو x[2n−3] ما تحلهاش في دماغك. الطريقة دي بتحل أي شكل:

  1. اكتب x جدول: كل n وقيمتها.
  2. لكل n جرب، احسب اللي جوه القوس.
  3. هات قيمة x عند الناتج. لو برة الجدول، تبقى صفر.
مثال كامل

x = {2, 1, 3} عند n = 0, 1, 2، والمطلوب y[n] = x[3−n].

n3−ny[n]
03x[3] = 0
12x[2] = 3
21x[1] = 1
30x[0] = 2
4−1x[−1] = 0

النتيجة: y = {3, 1, 2} عند n = 1, 2, 3.

تريك: عشان تعرف تجرب أنهي n: خلي اللي جوه القوس يساوي أول مكان وآخر مكان في x.
جرّب بنفسك: x = {2, 1, 3, 1} عند n = 0…3

x₁x₂النتيجة

الجزء 7

يعني إيه System؟

الـ system ماكينة: بتدخل لها إشارة x[n]، فتطلع إشارة y[n]. والمعادلة هي طريقة شغل الماكينة.

x[n] → [ T ] → y[n]
مثال

ماكينة y[n] = x[n] + x[n−1] بتجمع القيمة الحالية مع اللي قبلها. لو x = {1, 2, 3}:

y[0] = 1 + 0 = 1   y[1] = 2 + 1 = 3   y[2] = 3 + 2 = 5   y[3] = 0 + 3 = 3

أول خاصية: Memoryless

الماكينة بتحتاج تفتكر حاجة؟ لو الخرج بيعتمد على x[n] عند نفس اللحظة بس، تبقى Memoryless. ولو استخدمت قيمة تانية، زي x[n−1]، تبقى with memory.

y[n] = 2x[n] → memoryless    y[n] = x[n] + x[n−1] → with memory

الجزء 8

يعني إيه Linear؟ (أهم جزء)

الـ Linear معناها إن الماكينة عادلة ومتوقعة: لو ضاعفت الدخل، الخرج يتضاعف بالظبط. ولو دخلت حاجتين مع بعض، الخرج هو مجموع خرج كل واحدة لوحدها.

الشرط الأول: Homogeneity (الضرب)

جرب y = 2x بأرقام:

x = 3 → y = 6    ولو ضاعفنا: x = 6 → y = 12 = 2 × 6 ✓

دلوقتي جرب y = x + 1:

x = 3 → y = 4    ولو ضاعفنا: x = 6 → y = 7 ≠ 2 × 4 ✗

بالرموز: لازم T{c·x} = c·T{x}.

الشرط التاني: Additivity (الجمع)

جرب y = x² بـ x₁ = 1 وx₂ = 2:

T{1+2} = 3² = 9    T{1} + T{2} = 1 + 4 = 5 ✗

بالرموز: لازم T{x₁+x₂} = T{x₁} + T{x₂}.

Linear = الشرطين الاتنين مع بعض.

إزاي تعرفها من المعادلة في 3 أسئلة؟

  1. فيه رقم لوحده من غير x؟ زي +1. يبقى Nonlinear.
  2. x جوه دالة، أو مضروبة في x تانية، أو في مقام؟ زي x² أو log(x) أو |x| أو x[n]x[n−1]. يبقى Nonlinear.
  3. كل حد شكله (معامل) × x[حاجة]؟ يبقى Linear.
المعامل مسموح يكون فيه n: n·x[n] وx[n]sin(nπ/2) الاتنين Linear، لأن الدالة واقعة على n، مش على x.
المعادلةالسببالنتيجة
y = 3x[n]coefficient × xLinear
y = x[n] + x[n−1]every term × xLinear
y = n·x[n]coefficient is nLinear
y = x[n] + 5lone constantNonlinear
y = x[n]²x × xNonlinear
y = log(x[n])x inside a functionNonlinear

وفي الامتحان بتكتب إزاي؟

الأسئلة الـ 3 بتعرفك الإجابة، بس الإثبات لازم يتكتب. ومسألة y[n] = 2x[n] + x[n−1] بتتكتب كده:

Homogeneity

T{c x[n]} = 2c x[n] + c x[n−1] = c(2x[n] + x[n−1]) = c T{x[n]} ✓

Additivity

T{x₁+x₂} = 2(x₁[n]+x₂[n]) + (x₁[n−1]+x₂[n−1])

= (2x₁[n]+x₁[n−1]) + (2x₂[n]+x₂[n−1]) = T{x₁}+T{x₂} ✓

الشرطين اتحققوا، يبقى Linear.

ولو الـ system مش linear، مثال بأرقام واحد بيكفي:

مثال عكسي

y[n] = x[n] + 5: خد x = 1, c = 2:

T{2·1} = 7   2·T{1} = 12   7 ≠ 12 → Nonlinear

الجزء 9

يعني إيه Invariant و Variant؟

الـ Shift-Invariant معناها إن الماكينة ما بتتغيرش مع الوقت. لو شغلتها النهارده أو بكرة بنفس الدخل، هتطلع نفس الخرج، بس بتأخير. وVariant عكسها: الماكينة بتتصرف بشكل مختلف حسب اللحظة.

مثال من الحياة: آلة حاسبة بتدي نفس النتيجة في أي وقت، فهي Invariant. لكن مكيف بيقلل قوته كل ساعة أكتر، فهو Variant، لأن رده بيعتمد على الوقت.

نشوفها بأرقام

نختبر y[n] = n·x[n] بنبضة قيمتها 1:

النبضة عند n = 1: y[1] = 1×1 = 1

النبضة عند n = 5: y[5] = 5×1 = 5

نفس النبضة، بس الخرج اتغير من 1 لـ 5 لمجرد إننا غيرنا الوقت. يبقى Shift-Variant.

نختبر y[n] = 2x[n]: النبضة عند n = 1 تطلع 2، وعند n = 5 تطلع 2. نفس الرد، يبقى Shift-Invariant.

إزاي تعرفها من المعادلة؟

بص على n فين. عندك علامتين للـ Variant:

  1. n ظاهرة برة x كمعامل: زي n·x[n] وx[n]u[n] وx[n]sin(nπ/2).
  2. n جوه x مش بشكل n − رقم: زي x[2n] وx[−n] وx[n²].

لو n موجودة بس بشكل x[n − رقم] من غير أي معامل فيه n، يبقى Invariant.

المعادلةالنتيجة
y = x[n] + x[n−1]Invariant
y = x[n]²Invariant (rule has no n)
y = x[n−3] + 5Invariant
y = n·x[n]Variant
y = x[2n]Variant
y = x[−n]Variant
Linear وInvariant سؤالين منفصلين: x² Nonlinear بس Invariant. وn·x[n] Linear بس Variant.

وفي الامتحان بتكتب إزاي؟

الاختبار هو مقارنة طريقين:

  • الطريق الأول y₁[n]: أزيح الدخل. بدّل x بس، وn اللي برة تفضل زي ما هي.
  • الطريق التاني y[n−n₀]: أزيح الخرج. بدّل كل n بـ n−n₀.

لو الطريقين زي بعض، تبقى Invariant.

مثال 1: y[n] = x[n] + x[n−1]

y₁[n] = x[n−n₀] + x[n−1−n₀]

y[n−n₀] = x[n−n₀] + x[n−n₀−1]

زي بعض، يبقى Invariant.

مثال 2: y[n] = n·x[n]

y₁[n] = n·x[n−n₀]

y[n−n₀] = (n−n₀)·x[n−n₀]

مختلفين، يبقى Variant.

مثال 3: y[n] = x[2n]

y₁[n] = x[2n−n₀]

y[n−n₀] = x[2(n−n₀)] = x[2n−2n₀]

مختلفين، يبقى Variant.

فخ مثال 3: في y₁ الإزاحة بتتحط على n مباشرة جوه x، من غير ما تتضرب في 2.

معمل الاختبار: اختار system وشوف النتيجة بنفسك
الجزء 11

حل موجّه لمسائل الشيت

حاول الأول بالأسئلة اللي فوق، وبعدين افتح الحل. الحل مكتوب بالشكل اللي ينفع في الامتحان.

مسألة 1.7: x(n) = (6−n)[u(n) − u(n−6)]

الجدول: x = {6,5,4,3,2,1} عند n = 0…5.

(a) y₁(n) = x(4−n)
4−n من 0 لـ 5 يعني n من 4 لـ −1.
y₁ = {1,2,3,4,5,6} عند n = −1…4.
(b) y₂(n) = x(2n−3)
n=2 → x(1)=5، وn=3 → x(3)=3، وn=4 → x(5)=1. وعند n=1 الجوة −1، فالقيمة صفر.
(c) y₃(n) = x(8−3n)
n=1 → x(5)=1، وn=2 → x(2)=4. وعند n=0 الجوة 8، وعند n=3 الجوة −1، فالاتنين صفر.
(d) y₄(n) = x(n²−2n+1)
اللي جوه هو (n−1)². n=1 → x(0)=6، وn=0,2 → x(1)=5، وn=−1,3 → x(4)=2. وباقي القيم صفر.

مسألة 1.12: homogeneous؟ additive؟ linear؟

(a) y(n) = log(x(n))
log(cx) = log c + log x ≠ c·log x، يبقى مش homogeneous.
log(x₁+x₂) ≠ log x₁ + log x₂، يبقى مش additive. والنتيجة Nonlinear.
(b) y(n) = 6x(n+2) + 4x(n+1) + 2x(n) + 1
فيه +1 لوحده. T{cx} = c[…] + 1 وcT{x} = c[…] + c، فمش homogeneous.
T{x₁+x₂} = y₁ + y₂ − 1، فمش additive. والنتيجة Nonlinear.
(c) y(n) = 6x(n) + x(n+1)x(n−1)/x(n)
لو ضربنا x في c: الكسر فوق فيه c² وتحت c، فيفضل c واحدة. يبقى homogeneous.
لكن الكسر ما بيتقسمش على مجموع، فمش additive. والنتيجة Nonlinear.
(d) y(n) = x(n) sin(nπ/2)
T{ax₁+bx₂} = [ax₁+bx₂]sin(nπ/2) = ay₁ + by₂. يبقى Linear، يعني الاتنين homogeneous وadditive.
(e) y(n) = Re{x(n)}
Re{x₁+x₂} = Re{x₁} + Re{x₂}، يبقى additive.
لكن لو c complex، Re{cx} ≠ c·Re{x}. مثال: c = j وx = 1 بتدي 0 مقابل j. فمش homogeneous، والنتيجة Nonlinear.
(f) y(n) = ½[x(n) + x*(−n)]
الجمع بيتوزع عادي، يبقى additive.
لكن (cx)* = c*x*، فـ T{cx} = ½[cx(n) + c*x*(−n)] ≠ cT{x}. فمش homogeneous، والنتيجة Nonlinear.

مسألة 1.13: مثالين

(a) homogeneous بس مش additive. (b) additive بس مش homogeneous.
(a) y(n) = x(n−1)x(n)/x(n+1): الـ c بتطلع مرة واحدة، بس الكسر ما بيتوزعش.
(b) y(n) = Im{x(n)}: الجمع بيتوزع، بس Im{jx} ≠ j·Im{x}.

مسألة 1.14: shift-invariant؟

(a) y(n) = x(n) + x(n−1) + x(n−2)
y₁(n) = x(n−n₀) + x(n−n₀−1) + x(n−n₀−2) = y(n−n₀). يبقى Invariant.
(b) y(n) = x(n)u(n)
y₁(n) = x(n−n₀)u(n)، وy(n−n₀) = x(n−n₀)u(n−n₀). مختلفين، يبقى Variant. المعامل u(n) بيتغير مع n.
(c) y(n) = Σₖ₌₋∞ⁿ x(k)
y₁(n) = Σₖ₌₋∞ⁿ x(k−n₀). وبتعويض l = k−n₀ تبقى Σₗ₌₋∞ⁿ⁻ⁿ⁰ x(l) = y(n−n₀). يبقى Invariant.
(d) y(n) = x(n²)
مثال عكسي: x = δ(n) تدي y = δ(n). لكن x = δ(n−2) تدي δ(n²−2) = 0، ومش بتساوي y(n−2). يبقى Variant.
(e) y(n) = x((n))N
لو زحنا الدخل بـ N: y₁(n) = x((n−N))N = x((n))N، يعني نفس الخرج الأصلي، ومش مزاح. يبقى Variant.
(f) y(n) = x(−n)
y₁(n) = x(−n−n₀)، وy(n−n₀) = x(−n+n₀). مختلفين، يبقى Variant.

5 أسئلة سريعة

مسائل بأرقام جديدة

حل بالورقة الأول

1. أوجد y[n] = x[2−n] لـ x = {3, 1, 4} عند n = 0, 1, 2.
n=0 → x[2]=4، وn=1 → x[1]=1، وn=2 → x[0]=3. يبقى y = {4, 1, 3} عند n = 0, 1, 2.
2. x[n] = (5−n)[u(n) − u(n−5)]. أوجد y[n] = x[2n−2].
x = {5,4,3,2,1}. n=1 → x[0]=5، وn=2 → x[2]=3، وn=3 → x[4]=1. يبقى y = {5, 3, 1} عند n = 1…3.
3. اثبت إن y[n] = 3x[n] + x[n−2] Linear.
T{cx} = 3cx[n] + cx[n−2] = cT{x} ✓
T{x₁+x₂} = (3x₁[n]+x₁[n−2]) + (3x₂[n]+x₂[n−2]) = T{x₁}+T{x₂} ✓
يبقى Linear.
4. اثبت إن y[n] = x[n]² مش Linear بمثال.
x = 1, c = 2: T{2} = 4 و2T{1} = 2. مختلفين، يبقى Nonlinear.
5. حدد Invariant أو Variant: y[n] = x[n]cos(πn).
y₁[n] = x[n−n₀]cos(πn)، وy[n−n₀] = x[n−n₀]cos(π(n−n₀)). مختلفين، يبقى Variant.
6. حدد Invariant أو Variant: y[n] = x[n−1] + 4.
y₁[n] = x[n−n₀−1] + 4 = y[n−n₀]. يبقى Invariant. والـ 4 بتخليه Nonlinear، بس دي خاصية تانية.

5 سطور تراجعهم قبل الامتحان

  1. x[n−a] يمين، وx[n+a] شمال، وx[−n] مراية.
  2. أي تحريك مركب: جدول n ← اللي جوه القوس ← القيمة.
  3. Linear: مفيش constant لوحده، وx مش جوه دالة ومش مضروبة في x. والمعامل n مسموح.
  4. Invariant: n موجودة بس بشكل x[n − رقم]. ولو n معامل، أو x[2n] أو x[−n]، تبقى Variant.
  5. الإثبات: Linear بشرطين، وInvariant بمقارنة y₁[n] بـ y[n−n₀]، والنفي بمثال عكسي.
