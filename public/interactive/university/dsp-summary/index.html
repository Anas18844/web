الخريطة

Lec 1الـ signal دالة بتشيل معلومة، وخصايص الموجة Amplitude وFrequency وPhase.
الـ CT معرّفة في كل لحظة، والـ DT عند n صحيح بس.
طرق الكتابة: Graphical وFunctional وSequence.
Lec 2Duration: Finite وRight-sided وLeft-sided وTwo-sided.
Periodic لو N = 2πk/ω₀ طلع صحيح، ومن غير π تبقى aperiodic.
مجموع إشارتين: N = N₁N₂/gcd(N₁,N₂).
Lec 3x[n−n₀] يمين، وx[n+n₀] شمال، وx[−n] مراية.
أي تحريك مركب: جدول n ← الجوة ← القيمة.
Linear = Additive + Homogeneous، وأي constant بيكسرها.
Lec 4LSI معناها h[n] بتوصف الـ system كله.
Causal: h[n] = 0 لـ n < 0. Stable: Σ|h| < ∞.
y[n] = Σ x[k]h[n−k]، والبداية مجموع البدايتين، والطول Lₓ + Lₕ − 1.
Lec 5Convolution في الوقت = ضرب في التردد: Y = XH.
H(ejω) = Σ h[k]e−jωk.
|H| = √(Hr²+Hi²) وφ = tan⁻¹(Hi/Hr).

الامتحان التجريبي

4 أسئلة مقالية في 30 دقيقة

ده امتحان تقديري مني، مش امتحان سابق. حل في ورقة، والحلول هتظهر لما تضغط "خلصت".

30:00
السؤال 1
(a) Find the fundamental period of x[n] = cos(πn/5) + sin(πn/3).
(b) Find the even and odd parts of x[n] = {4 at n=−1, 2 at n=0, 0 at n=1}.
(a) N₁ = 10 وN₂ = 6، وgcd = 2، يبقى N = 30.
(b) xₑ = {2, 2, 2}، وxₒ = {2, 0, −2}.
السؤال 2
For y[n] = n x[n−1], determine: memoryless? linear? shift-invariant? causal? stable? invertible? Justify each.
With memory لأنها بتستخدم x[n−1]. Linear. Shift-varying لأن n معامل برة x. Causal. Unstable: لـ x = u[n]، الخرج بيكبر مع n. Not invertible: عند n = 0 الخرج صفر، فـ x[−1] بتضيع.
السؤال 3
(a) x = {2, −1, 3} at n = −1, 0, 1 and h = {1, 2} at n = 0, 1. Find y[n] = x[n] * h[n].
(b) Find (1/3)ⁿu[n] * u[n].
(a) y = {2, 3, 1, 6} عند n = −1…2. مراجعة: 12 = 4 × 3 ✓
(b) y[n] = (3/2)(1 − (1/3)ⁿ⁺¹)u[n]
السؤال 4
h[0] = 1 and h[2] = −1. Find H(ejω), |H|, and the phase. Evaluate them at ω = π/2.
H = 1 − e−j2ω = 2j sin(ω)e−jω
|H| = 2|sin ω|، و∠H = π/2 − ω لما sin ω > 0.
عند ω = π/2: H = 2، و|H| = 2، والـ phase صفر.
