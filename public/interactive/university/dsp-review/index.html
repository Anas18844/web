Lec 1 و 2 · الإشارات

الفرق بين Continuous-time و Discrete-time signal؟
Continuous x(t): معرّفة عند كل لحظة t.
Discrete x(n): معرّفة عند قيم n صحيحة بس.
δ(n) (unit impulse)؟
1 عند n = 0، وصفر عند أي n تانية.
u(n) (unit step)؟
1 لما n ≥ 0، وصفر لما n < 0.
δ(n) بدلالة u(n)؟
δ(n) = u(n) − u(n − 1)
u(n) − u(n − N) شكلها إيه؟
N واحدات من n = 0 لحد n = N − 1.
وعمومًا u(n − a) − u(n − b): واحدات من a لحد b − 1.
الأربع تصنيفات حسب المدة (duration)؟
• Finite-length: صفر برا فترة [N₁, N₂]
• Right-sided: صفر لكل n < n₀
• Left-sided: صفر لكل n > n₀
• Two-sided: لا نهائية من الناحيتين
صنّف: u(n+1) ، u(−n−3) ، (½)ⁿ ، u(n) − u(n−4)
right-sided ، left-sided ، two-sided ، finite-length
شرط الـ periodic؟ والـ fundamental period؟
x(n + N) = x(n) لكل n، و N صحيح موجب.
الـ fundamental period = أصغر N. ولو N period، يبقى 2N و 3N كمان periods.
أوجد N لـ cos(ω₀n)؟
N = 2πk / ω₀، وخد أصغر k تخلي N صحيح.
ولو ω₀ مفيهاش π (زي 0.2): aperiodic.
N لإشارتين متجمعين أو متضروبين؟
N = lcm(N₁, N₂) = N₁N₂ / gcd(N₁, N₂)
Even و Odd؟
Even: x(−n) = x(n) (متماثلة حوالين 0)
Odd: x(−n) = −x(n)، ولازم x(0) = 0
xₑ(n) و xₒ(n)؟
xₑ = ½[x(n) + x(−n)]
xₒ = ½[x(n) − x(−n)]
والمراجعة: xₑ + xₒ = x ، و xₑ(0) = x(0) ، و xₒ(0) = 0
even × odd ؟ even × even ؟ odd × odd ؟
odd ، even ، even (زي إشارات الأرقام: + × − = −)
الـ Conjugate symmetric part؟ وخواصها؟
xₑ = ½[x(n) + x*(−n)]
الجزء الحقيقي بتاعها even، والتخيلي odd.
ولو طلعت صفر: الإشارة conjugate antisymmetric.
Re{ejθ} و Im{ejθ} ؟
cos θ و sin θ

Lec 3 · Manipulations و System properties

x(n − n₀) بتعمل إيه؟
n₀ > 0: delay، يعني shift يمين.
n₀ < 0: advance، يعني shift شمال.
x(−n) ؟
Time reversal: اعكس حوالين n = 0. الـ index بس اللي بيتعكس، والقيم زي ما هي.
x(Mn) ؟
Downsampling: خد عينة كل M (الـ indices اللي بتقبل القسمة على M).
Upsampling بـ L ؟
حط L − 1 أصفار بين كل عينتين: y(n) = x(n/L) لو n من مضاعفات L، وصفر غير كده.
تحل x(an + b) إزاي من غير ما تتلخبط؟
اللي جوه القوس لازم يبقى جوه مدى x. حل المتباينة تطلع قيم n، وعوّض كل n.
الـ Amplitude manipulations؟
Addition و Multiplication (نقطة بنقطة عند نفس n) و Scaling بـ c.
Memoryless؟
y(n) معتمدة على x(n) بس عند نفس n. مثال: 2x(n). ولو فيها x(n−1): has memory.
Additive؟ ومثال مش additive؟
T{x₁ + x₂} = T{x₁} + T{x₂}
مش additive: x² (لأن (1+2)² = 9 ≠ 1 + 4)
Homogeneous؟ ومثال مش homogeneous؟
T{cx} = cT{x}
مش homogeneous: x + 1 (لأن 2x + 1 ≠ 2x + 2)
Linear؟ ومثال nonlinear؟
additive و homogeneous مع بعض:
T{ax₁ + bx₂} = aT{x₁} + bT{x₂}
Nonlinear: |x(n)|
Shift-invariant؟ وإزاي تختبره؟
زق الدخل، فالخرج يتزق بنفس المقدار.
قارن T{x(n − n₀)} (غيّر جوه x بس) بـ y(n − n₀) (غيّر كل n).
مثال shift-invariant ومثال shift-varying؟
SI: x²(n)
Varying: n x(n)
ينفع system يبقى SI و nonlinear؟
أيوه، زي x²(n). كل خاصية بتتختبر لوحدها.

Lec 4 · LSI و Convolution

LSI يعني إيه؟ وليه مهم؟
Linear + Shift-invariant.
الـ h(n) بيوصفه كله، والخرج = convolution.
h(n) ؟
الـ unit sample (impulse) response: خرج السيستم لما الدخل δ(n).
Causal؟ وشرطه في الـ LSI؟
بيستخدم الحاضر والماضي بس.
LSI: h(n) = 0 لكل n < 0
BIBO stable؟ وشرطه في الـ LSI؟
دخل محدود → خرج محدود.
LSI: Σₙ |h(n)| < ∞
Invertible؟
الخرج بيحدد الدخل بشكل وحيد. تثبتها بإنك تكتب x بدلالة y، وتنفيها بدخلين مختلفين بيدوا نفس y.
مثال مش invertible: x² (لأن 2 و −2 بيدوا 4).
قانون الـ Convolution؟
y(n) = x(n) * h(n) = Σₖ x(k) h(n − k)
الخرج بيبدأ فين وطوله قد إيه؟
البداية = بداية x + بداية h
الطول: Ly = Lₓ + Lₕ − 1
طريقة الجدول؟
y(n) = مجموع كل x(i)h(j) اللي فيها i + j = n. اعمل جدول ضرب، واجمع كل قطر.
مراجعة سريعة لأي convolution؟
Σy = Σx · Σh
Commutative و Associative و Distributive؟
x * h = h * x
(x * h₁) * h₂ = x * (h₁ * h₂): cascade
x * (h₁ + h₂) = x * h₁ + x * h₂: parallel
x(n) * δ(n − k) ؟
x(n − k)، يعني x اتزقت k.
حدود الـ Σ من الـ unit steps؟
u(k) → k ≥ 0
u(n − k) → k ≤ n
والاتنين: 0 ≤ k ≤ n، ولو n < 0: y = 0
مجموع المتسلسلة الهندسية؟
Σₖ₌₀ⁿ aᵏ = (1 − an+1) / (1 − a) ، ولو a = 1: n + 1
Σₖ₌₀^∞ aᵏ = 1/(1 − a) لما |a| < 1
aⁿu(n) * u(n) ؟
((1 − an+1) / (1 − a)) u(n) ، ولو a = 1: (n + 1)u(n)
الـ Correlation؟ والفرق بينها وبين الـ convolution؟
x ⋆ h = Σₖ x(k) h(n + k)
من غير قلب لـ h، بنزقها بس.
Cascade لاتنين LSI stable causal؟ ولاتنين nonlinear؟
الأول: الـ cascade كمان LSI و stable و causal.
التاني: مش لازم يطلع nonlinear (مثال: ex وبعده ln).

Lec 5 · Fourier

ليه Fourier؟
الـ convolution في الزمن = ضرب في التردد:
Y(ejω) = X(ejω) H(ejω)
لو الدخل ejωn داخل LSI، الخرج إيه؟
y(n) = H(ejω) ejωn
نفس التردد، والـ complex amplitude بس اللي بيتغير.
H(ejω) ؟
Σₖ h(k) e−jωk
Euler: e−jω ؟
cos ω − j sin ω
الـ Magnitude والـ Phase؟
H = Hᵣ + jHᵢ = |H|ejφ
|H| = √(Hᵣ² + Hᵢ²)
φ = tan⁻¹(Hᵢ / Hᵣ)، مع تصحيح الربع (atan2)
معنى |H| و φ ؟
|H|: السيستم بيكبّر الـ sinusoid أو يصغّره بقد إيه.
φ: بيزق الـ phase بتاعته قد إيه.
ejθ + e−jθ و ejθ − e−jθ ؟
2cos θ و 2j sin θ
1 + e−jω ؟
2cos(ω/2) e−jω/2
1 − e−jω ؟
2j sin(ω/2) e−jω/2
الوصفة لأي h قصيرة؟
1. اكتب Σ
2. طلّع نص الـ delay برا: e−jω(N−1)/2
3. Euler: الأقواس تبقى cos أو j sin
4. |H| = absolute الجزء الحقيقي، والـ phase = زاوية الـ e (و +π/2 لو فيه j)
H عند ω = 0 و ω = π ؟
Σ h(k) و Σ (−1)ᵏ h(k)
الـ Phase لما الجزء الحقيقي يبقى سالب؟ ولما H = 0؟
سالب: زوّد π.
H = 0: الـ phase undefined، واذكر الترددات دي.
h(n) = δ(n − d) ؟
H = e−jωd ، |H| = 1 ، φ = −dω
|ejθ| ؟ و |1 + j| وزاويته؟
1 ، و √2 بزاوية π/4

التريكات والفخاخ

x بتبدأ من −1 أو h من 2؟
سيب كل رقم بالـ index بتاعه. بداية y = مجموع البدايات.
خلصت convolution بأرقام؟
راجع Σy = Σx · Σh قبل ما تسلّم.
h فيها صفر في النص؟
سيب الصفر مكانه في الجدول. ما تشيلوش.
h فيها قيم قليلة متفرقة (زي 1.26)؟
اكتبها impulses: y = Σ cᵢ x(n − nᵢ). صفوف متزقوقة أسرع من جدول كبير.
الاتنين واحدات (u − u)؟
y = عدد الخانات المتداخلة، والشكل trapezoid: يطلع، وبعدين يثبت، وبعدين ينزل.
sin(π + 0.2n) periodic؟
الـ π اللي برا n دي phase ملهاش دعوة. ω₀ = 0.2 → aperiodic.
فيها Re{} أو Im{} في الـ period؟
حوّلها لـ cos و sin الأول، وبعدين lcm.
اختبار الـ SI بيتلخبط؟
T{x(n−n₀)}: غيّر جوه x بس. y(n−n₀): غيّر كل n. وأي n برا x أو x(−n) أو x(2n) أو x(n²) → غالبًا varying.
Re{} أو conjugate في اختبار الـ linearity؟
جرّب c = j. بتبوظ الـ homogeneity، فبتبقى additive only.
فيه ثابت لوحده (+1)؟
مش homogeneous ومش additive → neither.
اختبار الـ causality؟
جرّب n سالبة (n = −1): x(|n|) و x(n² − n) بيطلبوا مستقبل.
اختبار الـ stability بسرعة؟
جرّب x = u(n) أو δ(n). الـ accumulator Σ لحد n → unstable. والقسمة على x → unstable.
اختبار الـ invertibility بسرعة؟
دوّر على معلومة بتضيع: n x(n) عند 0، والفرق بيضيّع الثابت، و Re بيضيّع التخيلي.
Fourier: خلصت H؟
اختبر عند ω = 0 (لازم = Σh) وعند ω = π.
المتسلسلة الهندسية فيها a؟
اكتب حالة a = 1 لوحدها (n + 1)، والقانون لما a ≠ 1.
إشارة محدودة مع لا نهائية (زي 1.34)؟
3 حالات: n < 0، وجوه مدى الإشارة المحدودة، وبعد آخرها. والحد الأعلى للـ Σ = الأصغر من n وآخر الإشارة.

Problem 2 · Convolution with a negative starting index

Let x[−1] = 2, x[0] = 1, x[1] = 3 and h[0] = 1, h[1] = −1, h[2] = 2. Calculate y[n] = x[n] * h[n].
1. اكتب القيم بالـ indexخد بالك: x بتبدأ من −1 مش من 0. ده الفخ بتاع المسألة.
x[−1] = 2 , x[0] = 1 , x[1] = 3
h[0] = 1 , h[1] = −1 , h[2] = 2
2. البداية والطول• البداية = −1 + 0 = −1
• الطول = 3 + 3 − 1 = 5
يبقى n من −1 لحد 3.
3. جدول الضربكل خانة مكتوب تحتها هي بتروح لأنهي y. الخانات اللي بنفس اللون بتتجمع:
h[0] = 1h[1] = -1h[2] = 2
x[-1] = 22y[-1]-2y[0]4y[1]
x[0] = 11y[0]-1y[1]2y[2]
x[1] = 33y[1]-3y[2]6y[3]
4. y[−1] و y[0]
y[−1] = x[−1]h[0] = 2×1 = 2
y[0] = x[−1]h[1] + x[0]h[0] = 2×(−1) + 1×1 = −2 + 1 = −1
5. y[1]: الخانة اللي فيها 3 حدودالأزواج: (−1, 2) و (0, 1) و (1, 0).
y[1] = x[−1]h[2] + x[0]h[1] + x[1]h[0] = 2×2 + 1×(−1) + 3×1 = 4 − 1 + 3 = 6
6. y[2] و y[3]
y[2] = x[0]h[2] + x[1]h[1] = 1×2 + 3×(−1) = 2 − 3 = −1
y[3] = x[1]h[2] = 3×2 = 6
7. راجع واكتب الإجابةΣy = 2 − 1 + 6 − 1 + 6 = 12 و Σx · Σh = 6 × 2 = 12 ✓
y[n] = {2, −1, 6, −1, 6} , n = −1, …, 3

Problem 7 · Convolution of infinite-duration sequences

Let x[n] = aⁿu[n] and h[n] = u[n], where a is a real constant. Find y[n] = x[n] * h[n] for a ≠ 1, then state the result when a = 1. Include the case n < 0.
1. الإشارات لا نهائية، فمفيش جدول. نكتب القانون
y[n] = Σₖ x[k] h[n−k] = Σₖ aᵏu[k] · u[n−k]
الشغل كله إننا نعرف حدود الـ Σ من الـ unit steps.
2. الشرط الأول من xu[k] = 1 بس لما k ≥ 0. يعني الجمع بيبدأ من k = 0.
3. الشرط التاني من hu[n−k] = 1 بس لما n − k ≥ 0، يعني k ≤ n. يعني الجمع بيقف عند k = n.
4. حط الشرطين مع بعض
0 ≤ k ≤ n
• لو n < 0: مفيش k تحقق الشرطين (مفيش overlap) → y[n] = 0
• لو n ≥ 0:
y[n] = Σₖ₌₀ⁿ aᵏ = 1 + a + a² + … + aⁿ
5. قانون الـ geometric series (لما a ≠ 1)متسلسلة هندسية: أول حد 1، والأساس a، وعدد الحدود n + 1.
Σₖ₌₀ⁿ aᵏ = (1 − an+1) / (1 − a)
جرّب n = 1: (1 − a²)/(1 − a) = 1 + a ✓
6. الحالة a = 1القانون فيه 1 − a في المقام، فلو a = 1 بيبقى قسمة على صفر. بنرجع للجمع نفسه: 1 + 1 + … + 1، وعددهم n + 1.
y[n] = n + 1 , n ≥ 0
7. اكتب الإجابة النهائيةالـ u[n] بتلم الحالتين (n < 0 صفر، و n ≥ 0 القانون):
y[n] = ((1 − an+1) / (1 − a)) u[n] , a ≠ 1
y[n] = (n + 1) u[n] , a = 1

H = cos(ω/2) e−jω/2

|H| = |cos(ω/2)|

• لما cos(ω/2) > 0 (يعني |ω| < π): ∠H = −ω/2
• لو بقى سالب: زوّد π (السالب = زاوية π)
• عند ω = ±π: cos(π/2) = 0، فـ H = 0 والـ phase undefined
6. اكتب الإجابة
H = cos(ω/2)e−jω/2 , |H| = |cos(ω/2)| , ∠H = −ω/2 (|ω| < π)
ده lowpass: عند ω = 0 الطول 1، وعند ω = π صفر.

1.1 · Periodic or not

Determine whether the signals are periodic and find the fundamental period: (a) cos(0.125πn) (b) Re{ejnπ/12} + Im{ejnπ/18} (c) sin(π + 0.2n) (d) ej(π/16)n cos(nπ/17)
1. القاعدةإشارة متقطعة cos(ω₀n) تبقى periodic بس لو فيه N صحيح يحقق ω₀N = 2πk.
قانون الـ period: N = 2πk / ω₀، ودوّر على أصغر k تخلي N رقم صحيح.
ولو فيه إشارتين متجمعين أو متضروبين: N = lcm(N₁, N₂).
2. (a) cos(0.125πn)ω₀ = 0.125π = π/8
N = 2πk / (π/8) = 16k → k = 1 , N = 16
3. (b) فك الـ Re والـ Im الأولRe{ejθ} = cos θ و Im{ejθ} = sin θ، يعني x = cos(nπ/12) + sin(nπ/18).
• N₁ = 2π/(π/12) = 24
• N₂ = 2π/(π/18) = 36
N = lcm(24, 36) = 72
4. (c) sin(π + 0.2n)الـ π اللي جوه دي phase، ملهاش دعوة بالـ period. ω₀ = 0.2:
N = 2πk / 0.2 = 10πk
مفيش k صحيح يخلي 10πk رقم صحيح (π مش بتروح) → not periodic.
5. (d) حاصل ضرب• ejπn/16: N₁ = 2π/(π/16) = 32
• cos(nπ/17): N₂ = 2πk/(π/17) = 34k → 34
N = lcm(32, 34) = (32 × 34)/2 = 544

1.14 · Shift-invariant or not

Is each system shift-invariant? (a) x(n) + x(n−1) + x(n−2) (b) x(n)u(n) (c) Σk=−∞n x(k) (d) x(n²) (e) x((n))N (f) x(−n)
1. الاختباراختبار الـ shift-invariance: احسب (1) خرج الإشارة المتزقوقة T{x(n−n₀)}، و (2) الخرج المتزقوق y(n−n₀) (يعني بدّل كل n بـ n−n₀). لو طلعوا زي بعض → SI.
تريك سريع: لو n ظاهرة برا x (زي u(n) أو n x)، أو جوه القوس متضروبة أو متربعة أو بإشارة سالبة → غالبًا varying.
2. (a)T{x(n−n₀)} = x(n−n₀) + x(n−n₀−1) + x(n−n₀−2) = y(n−n₀) → SI
3. (b) x(n)u(n)T{x(n−n₀)} = x(n−n₀)u(n)
y(n−n₀) = x(n−n₀)u(n−n₀)
مختلفين (u(n) ما اتزقتش) → shift-varying
4. (c) الـ accumulatorT{x(n−n₀)} = Σk≤n x(k−n₀)، وبالتعويض m = k − n₀: = Σm≤n−n₀ x(m) = y(n−n₀) → SI
5. (d) x(n²)T{x(n−n₀)} = x(n² − n₀)
y(n−n₀) = x((n−n₀)²)
مختلفين → varying
6. (e) x((n))Nده بياخد n mod N، يعني بيكرر أول N عينة بس. لو زقيت x الأول، العينات اللي داخلة في [0, N−1] بتتغير، فالنتيجة مش هي هي الخرج متزقوق. مثال N = 3 و n₀ = 1 عند n = 0: الأول بيدي x(−1) والتاني x(2) → varying
7. (f) x(−n)T{x(n−n₀)} = x(−n − n₀)
y(n−n₀) = x(−(n−n₀)) = x(−n + n₀)
مختلفين → varying
